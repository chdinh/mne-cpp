# ConnectivitySettings

**Namespace:** `CONNECTIVITYLIB` &nbsp;·&nbsp; **Library:** Connectivity Library &nbsp;·&nbsp; **Source:** [`connectivity/connectivitysettings.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/connectivity/connectivitysettings.h)

`#include <connectivity/connectivitysettings.h>`

<Connections topics={["connectivity"]} context="api" current="ConnectivitySettings" />

```cpp
class CONNECTIVITYLIB::ConnectivitySettings
```

Mutable container that aggregates the inputs and intermediate spectral results required by every metric implementation in ``CONNECTIVITYLIB``.

Each call to `CONNECTIVITYLIB::ConnectivitySettings::append` "append" adds one trial; the trial matrices live in `m_trialData`, while DPSS tapered spectra, cross-spectral densities and their imaginary-part derivatives are filled in lazily by whichever metric runs first. Cross-trial sums accumulate in `m_intermediateSumData` so that a second metric run on the same data set reuses those sums and skips the FFT pass entirely. Node positions can be derived from a `FiffInfo` (sensor space) or from a forward solution + `FsSurfaceSet` (source space) and are propagated into the resulting [`Network`](/docs/api/connectivity/network) nodes.

Aggregates trial data, spectral cache and node geometry shared by all ``CONNECTIVITYLIB`` metrics.

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
ConnectivitySettings settings;
for (int i = 0; i < kTrials; ++i) {
    settings.append(makeTrial(gen)); // channels x samples, one call per trial
}
settings.setSamplingFrequency(kSFreq);
settings.setFFTSize(kSamples);
settings.setWindowType("hanning");

MatrixX3f positions(3, 3);
positions << 0.0f, 0.0f, 0.0f, 0.05f, 0.0f, 0.0f, 0.0f, 0.05f, 0.0f;
settings.setNodePositions(positions);
```

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
settings.setConnectivityMethods({"COH", "PLV", "WPLI"});
std::vector<Network> networks = compute_connectivity(settings);
for (Network network : networks) {
    network.setFrequencyRange(8.0f, 12.0f); // average the per-bin weights over the alpha band
    std::println("{} 0-1: {:g}", network.getConnectivityMethod().toStdString(), edgeWeight(network, 0, 1));
}
```

````cpp title="src/examples/ex_dsp_rt/main.cpp, line 242"
// ---------------------------------------------------------------------------------------------------------
// Connectivity: the same network as compute_connectivity, computed on a worker thread
ConnectivitySettings settings;
for (int trial = 0; trial < 5; ++trial) {
    MatrixXd data(2, 256);
    for (int t = 0; t < 256; ++t) {
        const double alpha = std::sin(2.0 * kPi * 10.0 * t / 256.0 + trial);
        data(0, t) = alpha + 0.3 * normal(gen) * 1e12;
        data(1, t) = alpha + 0.3 * normal(gen) * 1e12;
    }
    settings.append(data);
}
settings.setSamplingFrequency(256);
settings.setFFTSize(256);
````
