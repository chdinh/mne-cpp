# NetworkNode

**Namespace:** `CONNECTIVITYLIB` &nbsp;·&nbsp; **Library:** Connectivity Library &nbsp;·&nbsp; **Source:** [`connectivity/network/networknode.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/connectivity/network/networknode.h)

`#include <connectivity/networknode.h>`

```cpp
class CONNECTIVITYLIB::NetworkNode
```

Node of a [`Network`](/docs/api/connectivity/network): a 3D position (sensor coordinate or source vertex), a hub flag, and the indices into `Network::edges` of every edge that starts or ends at this node.

Degree and strength are computed by `Network::degree` and `Network::strength`.

[Graph](/docs/api/disp/graph) node carrying a 3D position and the indices of its incident edges.

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
Network network("manual");
for (int i = 0; i < 3; ++i) {
    network.add_node(positions.row(i).transpose());
}
network.add_edge(NetworkEdge(0, 1, MatrixXd::Constant(1, 1, 0.9))); // one weight per frequency bin
network.add_edge(NetworkEdge(1, 2, MatrixXd::Constant(1, 1, 0.2)));
```
