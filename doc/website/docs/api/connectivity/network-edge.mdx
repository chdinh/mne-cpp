# NetworkEdge

**Namespace:** `CONNECTIVITYLIB` &nbsp;·&nbsp; **Library:** Connectivity Library &nbsp;·&nbsp; **Source:** [`connectivity/network/networkedge.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/connectivity/network/networkedge.h)

`#include <connectivity/networkedge.h>`

```cpp
class CONNECTIVITYLIB::NetworkEdge
```

Directed weighted edge between the nodes with indices `source` and `target`.

Holds the full per-frequency weight matrix delivered by the metric, the frequency-bin window that reduces it to the scalar `weight`, and the active flag set by `Network::set_threshold`. For symmetric metrics the direction is a storage convention only.

[`NetworkEdge`](/docs/api/connectivity/network-edge) is a plain value type: copies are independent.

Weighted, directional edge in a [`Network`](/docs/api/connectivity/network); carries per-frequency weights plus a band-averaged scalar.

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
Network network("manual");
for (int i = 0; i < 3; ++i) {
    network.add_node(positions.row(i).transpose());
}
network.add_edge(NetworkEdge(0, 1, MatrixXd::Constant(1, 1, 0.9))); // one weight per frequency bin
network.add_edge(NetworkEdge(1, 2, MatrixXd::Constant(1, 1, 0.2)));
```

## Public Methods

### NetworkEdge(source, target, weights, bins)

Constructs an edge and computes its scalar weight.

**Parameters:**

- **source** : *int*
  Index of the start node.

- **target** : *int*
  Index of the end node.

- **weights** : *Eigen::MatrixXd*
  Per-frequency weights, one row per bin. An empty matrix becomes a 1x1 zero matrix.

- **bins** : *std::pair&lt; int, int &gt;*
  Inclusive frequency-bin window to average; \{-1, -1\} averages all weights.

**Returns:**

---

### set_frequency_bins(bins)

Sets the frequency-bin window and recomputes the scalar weight.

Invalid windows (last before first, or indices below -1) are stored but leave the weight unchanged. A window reaching past the last bin is clipped.

**Parameters:**

- **bins** : *std::pair&lt; int, int &gt;*
  The inclusive window; \{-1, -1\} averages all bins.
