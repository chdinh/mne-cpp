# Network

**Namespace:** `CONNECTIVITYLIB` &nbsp;·&nbsp; **Library:** Connectivity Library &nbsp;·&nbsp; **Source:** [`connectivity/network/network.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/connectivity/network/network.h)

`#include <connectivity/network.h>`

```cpp
class CONNECTIVITYLIB::Network
```

[Graph](/docs/api/disp/graph) container for one functional-connectivity result.

Holds the nodes (channel / source positions) and the edges (per-frequency weight matrices + scalar band-averaged weights), the metric name ("COH", "PLI", "GC", ...), the threshold that marks edges active, and the [`VisualizationInfo`](/docs/api/connectivity/visualization-info) read by the disp3D rendering layer. Edges are read-only once added so that the cached weight ranges stay consistent.

[Graph](/docs/api/disp/graph) container for one connectivity metric; nodes + weighted edges + threshold/visualisation state.

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
Network network("manual");
for (int i = 0; i < 3; ++i) {
    network.add_node(positions.row(i).transpose());
}
network.add_edge(NetworkEdge(0, 1, MatrixXd::Constant(1, 1, 0.9))); // one weight per frequency bin
network.add_edge(NetworkEdge(1, 2, MatrixXd::Constant(1, 1, 0.2)));
```

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
network.set_threshold(0.5);
const MatrixXd adjacency = network.connectivity_matrix(); // symmetric by default
const std::size_t strongEdges = network.edge_count(EdgeSet::thresholded);
const int hubDegree = network.degree(1);
const int hubStrongDegree = network.degree(1, EdgeSet::thresholded);
const double hubStrength = network.strength(1);
network.set_visualization_info({.coloring = VisualizationInfo::Coloring::fixed, // how disp3D colours the network
                                .edge_color = Eigen::Vector4i(0, 0, 255, 255)});
```

````cpp title="src/examples/ex_connectivity_metrics/main.cpp, line 116"
/**
 * Band-averaged weight of the edge start -> end, or -1 if the network has no such edge.
 */
double edgeWeight(const Network& network, int start, int end)
{
    for (const NetworkEdge& edge : network.edges()) {
        if (edge.source() == start && edge.target() == end) {
            return edge.weight();
        }
    }
    return -1.0;
}
````
