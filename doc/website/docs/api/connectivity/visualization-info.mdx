# VisualizationInfo

**Namespace:** `CONNECTIVITYLIB` &nbsp;·&nbsp; **Library:** Connectivity Library &nbsp;·&nbsp; **Source:** [`connectivity/network/network.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/connectivity/network/network.h)

`#include <connectivity/network.h>`

```cpp
struct CONNECTIVITYLIB::VisualizationInfo
```

Per-network rendering hints: colour map or fixed RGBA for nodes and edges.

```cpp title="src/examples/ex_connectivity_metrics/main.cpp"
network.set_threshold(0.5);
const MatrixXd adjacency = network.connectivity_matrix(); // symmetric by default
const std::size_t strongEdges = network.edge_count(EdgeSet::thresholded);
const int hubDegree = network.degree(1);
const int hubStrongDegree = network.degree(1, EdgeSet::thresholded);
const double hubStrength = network.strength(1);
network.set_visualization_info({.coloring = VisualizationInfo::Coloring::fixed, // how disp3D colours the network
                                .edge_color = Eigen::Vector4i(0, 0, 255, 255)});
```

### [ex_connectivity_metrics](../../examples/connectivity/ex_connectivity_metrics.mdx)

Connectivity metrics on synthetic data with a known coupling.

````cpp title="src/examples/ex_connectivity_metrics/main.cpp, line 296"
const int hubDegree = network.degree(1);
const int hubStrongDegree = network.degree(1, EdgeSet::thresholded);
const double hubStrength = network.strength(1);
network.set_visualization_info({.coloring = VisualizationInfo::Coloring::fixed, // how disp3D colours the network
                                .edge_color = Eigen::Vector4i(0, 0, 255, 255)});
ok &= expect(adjacency(1, 0) == 0.9 && adjacency(2, 1) == 0.2 && strongEdges == 1 && network.visualization_info().edge_color(2) == 255,
             "manual network: mirrored adjacency, one edge above 0.5");
ok &= expect(hubDegree == 2 && hubStrongDegree == 1 && std::fabs(hubStrength - 1.1) < 1e-12,
             "node 1: degree 2, thresholded degree 1, strength 1.1");
````
