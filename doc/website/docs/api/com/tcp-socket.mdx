# TcpSocket

**Namespace:** `COMLIB` &nbsp;·&nbsp; **Library:** Communication Library &nbsp;·&nbsp; **Source:** [`com/tcp_socket.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/com/tcp_socket.h)

`#include <com/tcp_socket.h>`

```cpp
class COMLIB::TcpSocket
```

A connected TCP socket; move-only, closed on destruction.

```cpp title="src/examples/ex_com/main.cpp"
auto server = TcpSocket::connect("127.0.0.1", 1, 500ms);
if (!server) {
    std::println("no server: {}", server.error().message());
}
```

### read(buffer, timeout)

Reads exactly `buffer.size()` bytes.

**Parameters:**

- **buffer** : *std::span&lt; std::byte &gt;*
  Destination.

- **timeout** : *std::chrono::milliseconds*
  Maximum wait for the first byte; the rest must follow within it too.

**Returns:**

- *std::error_code* — timed_out if nothing arrived (nothing is consumed then), io_error if the rest did not follow, connection_reset if the peer closed the connection, or the system's error.

### connect(host, port, timeout)

**Parameters:**

- **host** : *const std::string &*
  Host name or address.

- **port** : *std::uint16_t*
  Port.

- **timeout** : *std::chrono::milliseconds*
  Maximum wait for the connection.

**Returns:**

- *std::expected&lt; TcpSocket, std::error_code &gt;* — The connection, or why there is none: host_unreachable for an unknown host, timed_out if nothing answers, the system's error otherwise (e.g. connection_refused).

````cpp title="src/examples/ex_com/main.cpp, line 107"
std::println("TCP: nothing serves port 1 of this machine");
auto server = TcpSocket::connect("127.0.0.1", 1, 500ms);
if (!server) {
    std::println("no server: {}", server.error().message());
}
ok &= expect(!server, "connecting fails with the system's reason");
ok &= expect(TcpSocket::connect("no-such-host.invalid", 4217, 500ms).error() == std::errc::host_unreachable,
             "an unknown host is host_unreachable");
````
