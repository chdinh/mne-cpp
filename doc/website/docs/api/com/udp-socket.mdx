# UdpSocket

**Namespace:** `COMLIB` &nbsp;·&nbsp; **Library:** Communication Library &nbsp;·&nbsp; **Source:** [`com/udp_socket.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/com/udp_socket.h)

`#include <com/udp_socket.h>`

```cpp
class COMLIB::UdpSocket
```

A bound UDP socket; move-only, closed on destruction.

```cpp title="src/examples/ex_com/main.cpp"
auto udp = UdpSocket::bind("127.0.0.1", 0); // 0: the system chooses the port
if (!udp) {
    std::println("cannot receive: {}", udp.error().message());
    return EXIT_FAILURE;
}
send_datagram(udp->port(), "sample block");
std::array<std::byte, 1500> datagram{};
const auto size = udp->receive(datagram, 1s);
```

### send_to(datagram, address, port)

Sends one datagram.

To a multicast group it leaves through the interface of the default route and also reaches the members on this machine.

**Parameters:**

- **datagram** : *std::span&lt; const std::byte &gt;*
  The datagram.

- **address** : *const std::string &*
  Destination IPv4 address.

- **port** : *std::uint16_t*
  Destination port.

**Returns:**

- *std::error_code* — Empty, invalid_argument for an address that is no IPv4 address, or the system's error.

## Static Methods

### bind(address, port)

**Parameters:**

- **address** : *const std::string &*
  Local IPv4 address to receive on, e.g. 0.0.0.0 for all; a multicast group (224.0.0.0 to 239.255.255.255) is joined on the interface of the default route, and its port is shared with the other members on this machine.

- **port** : *std::uint16_t*
  Local port; 0 lets the system choose one.

**Returns:**

- *std::expected&lt; UdpSocket, std::error_code &gt;* — The bound socket, invalid_argument for an address that is no IPv4 address, or the system's error (e.g. address_in_use).

````cpp title="src/examples/ex_com/main.cpp, line 93"
std::println("UDP: a device sends datagrams to a port");
auto udp = UdpSocket::bind("127.0.0.1", 0); // 0: the system chooses the port
if (!udp) {
    std::println("cannot receive: {}", udp.error().message());
    return EXIT_FAILURE;
}
send_datagram(udp->port(), "sample block");
std::array<std::byte, 1500> datagram{};
const auto size = udp->receive(datagram, 1s);
ok &= expect(size && *size == 12, "one datagram of 12 bytes arrives");
ok &= expect(udp->receive(datagram, 50ms).error() == std::errc::timed_out, "no second one: timed_out");
````
