# MriMghIO

**Namespace:** `MRILIB` &nbsp;·&nbsp; **Library:** MRI Library &nbsp;·&nbsp; **Source:** [`mri/mri_mgh_io.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mri/mri_mgh_io.h)

`#include <mri/mri_mgh_io.h>`

```cpp
class MRILIB::MriMghIO
```

Stateless decoder for FreeSurfer MGH and MGZ volume containers.

Parses the 284-byte big-endian header, decodes the column-major voxel buffer for every supported MRI type (uchar, int, float, short) and reads the optional tag footer (scan parameters, `talairach.xfm` path) into an [`MriVolData`](/docs/api/mri/mri-vol-data). .mgz inputs are inflated in-memory through zlib's `MAX_WBITS+16` gunzip mode before parsing, so callers never need to know whether they are looking at the compressed or uncompressed variant.

Format reference: [https://surfer.nmr.mgh.harvard.edu/fswiki/FsTutorial/MghFormat](https://surfer.nmr.mgh.harvard.edu/fswiki/FsTutorial/MghFormat)

Ported from `make_mgh_cor_set()` in [MNE](/docs/api/mne/mne-class) C `mne_make_cor_set` by Matti Hamalainen.

```cpp title="src/examples/ex_mri/main.cpp"
MriVolData mgh;
std::vector<FiffCoordTrans> extraTransforms; // e.g. Talairach, if the footer names one
MriMghIO::read((dataDir + "/gradient.mgz").toStdString(), mgh, extraTransforms);
const Matrix4f vox2ras = mgh.computeVox2Ras();            // scanner RAS, metres
const std::vector<float> voxels = mgh.voxelDataAsFloat(); // x fastest
```

## Static Methods

### read(mgzFile, volData, additionalTrans, subjectMriDir, verbose)

Reads a FreeSurfer MGH or MGZ file.

Parses the header geometry (dimensions, voxel sizes, direction cosines, center RAS), reads voxel data into per-slice [`MriSlice`](/docs/api/mri/mri-slice) structures, and extracts footer tags including the Talairach .xfm path.

For .mgz files, automatic gzip decompression is performed via zlib.

**Parameters:**

- **mgzFile** : *const std::string &*
  Path to the .mgz or .mgh file.

- **volData** : *[MriVolData](/docs/api/mri/mri-vol-data) &*
  [`MriVolData`](/docs/api/mri/mri-vol-data) structure to populate.

- **additionalTrans** : *std::vector&lt; [FiffCoordTrans](/docs/api/fiff/fiff-coord-trans) &gt; &*
  Surface RAS -&gt; RAS and, if the footer names a talairach.xfm, the Talairach chain of [`FiffCoordTransSet`](/docs/api/fiff/fiff-coord-trans-set).

- **subjectMriDir** : *const std::string &*
  Path to subject's mri/ directory (for resolving relative .xfm paths).

- **verbose** : *bool*
  If true, print progress information.

**Returns:**

- *bool* — True on success, false on error.
