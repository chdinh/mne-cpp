# PythonRunner

**Namespace:** `PYBRIDGELIB` &nbsp;·&nbsp; **Library:** Python Bridge Library &nbsp;·&nbsp; **Source:** [`pybridge/python_runner.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/pybridge/python_runner.h)

`#include <pybridge/python_runner.h>`

```cpp
class PYBRIDGELIB::PythonRunner
```

Runs Python scripts and one-liners in a child process.

Output is streamed line by line to the optional callbacks and to [`Log`](/docs/api/base/log), and collected into the [`PythonRunnerResult`](/docs/api/pybridge/python-runner-result). Lines of the form `"[progress] 42.5%"` or `"[progress] 42.5% Training epoch 10/50"` are reported as progress. No Python embedding or linkage is required.

Python script launcher with streaming output and progress reporting.

```cpp title="src/examples/ex_pybridge/main.cpp"
PythonRunner python; // "python3" from PATH; a timeout or venv is set via PythonRunnerConfig
std::vector<std::string> progress;
python.set_progress_callback([&](float pct, std::string_view message) { progress.push_back(std::format("{} {}", pct, message)); });
const PythonRunnerResult run = python.run_code("import sys\nprint('[progress] 50% half')\nprint(sum(map(int, sys.argv[1:])))", {"2", "3"});
```

### is_package_available(package)

Checks whether a package can be imported, without importing it.

**Parameters:**

- **package** : *std::string_view*
  Module name, e.g. "mne" or "sklearn"; anything but a dotted Python identifier is rejected.

**Returns:**

- *bool* — True if `importlib.util.find_spec` finds the package.

---

### ensure_venv()

Prepares the configured virtual environment: creates it if needed, installs `package_dir` (preferred) or `requirements_file` into it, and switches `python_exe` to the venv interpreter.

Without a `venv_dir` it does nothing and succeeds.

**Returns:**

- *[PythonRunnerResult](/docs/api/pybridge/python-runner-result)* — The outcome of the venv setup.

---

### run_in_venv(script, args)

Calls `ensure_venv`, then runs the script inside the venv.

**Parameters:**

- **script** : *const std::filesystem::path &*
  Path of the .py file.

- **args** : *const BASELIB::StringList &*
  Arguments passed to the script.

**Returns:**

- *[PythonRunnerResult](/docs/api/pybridge/python-runner-result)* — The venv setup error, or the outcome of the run.

---

### venv_python_path()

**Returns:**

- *std::filesystem::path* — The interpreter inside `venv_dir`, or an empty path if no venv is configured.
