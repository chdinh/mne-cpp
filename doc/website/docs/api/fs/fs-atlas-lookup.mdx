# FsAtlasLookup

**Namespace:** `FSLIB` &nbsp;·&nbsp; **Library:** FreeSurfer Library &nbsp;·&nbsp; **Source:** [`fs/fs_atlas_lookup.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fs/fs_atlas_lookup.h)

`#include <fs/fs_atlas_lookup.h>`

```cpp
class FSLIB::FsAtlasLookup
```

RAS-point → anatomical-region resolver backed by a FreeSurfer volumetric parcellation.

Owns the parcellation voxel grid, its inverse RAS-to-voxel affine, and a label-id → region-name map seeded from FreeSurferColorLUT. Designed for cheap per-point queries: a ``label_at_ras()`` call is an affine transform, three bound checks and an `int` → name hash lookup.

```cpp title="src/examples/ex_fs/main.cpp"
QTemporaryDir dir;
const QString atlasPath = dir.filePath("atlas.mgh"); // normally aparc+aseg.mgz
writeAtlas(atlasPath);
FsAtlasLookup atlas;
atlas.load(atlasPath.toStdU16String());
const std::vector<Vector3f> points{Vector3f(-4.0f, -4.0f, -4.0f), Vector3f(2.0f, 0.0f, -2.0f), Vector3f(0.0f, 0.0f, 0.0f)};
const std::vector<std::string> regionsAt = atlas.labels_for_positions(points);
```

## Public Methods

### load(parcellation)

Load a FreeSurfer MGH or gzip-compressed MGZ volume parcellation.

**Parameters:**

- **parcellation** : *const std::filesystem::path &*
  The volume file (e.g. aparc+aseg.mgz).

**Returns:**

- *bool* — true if loaded successfully.

---

### label_at_ras(ras)

Look up the anatomical label at a RAS coordinate.

**Parameters:**

- **ras** : *const Eigen::Vector3f &*
  3D position in RAS space (in mm).

**Returns:**

- *const std::string &* — Region name, or "Unknown" if out of bounds or unlabeled.

---

### labels_for_positions(positions)

Look up labels for multiple RAS positions.

**Parameters:**

- **positions** : *std::span&lt; const Eigen::Vector3f &gt;*
  3D RAS positions.

**Returns:**

- *std::vector&lt; std::string &gt;* — One region name per position.

---

### is_loaded()

Check whether a parcellation volume has been loaded.

**Returns:**

- *bool* — true if loaded.

FreeSurfer library: surfaces, curvature, parcellations, labels and an atlas volume.

````cpp title="src/examples/ex_fs/main.cpp, line 175"
QTemporaryDir dir;
const QString atlasPath = dir.filePath("atlas.mgh"); // normally aparc+aseg.mgz
writeAtlas(atlasPath);
FsAtlasLookup atlas;
atlas.load(atlasPath.toStdU16String());
const std::vector<Vector3f> points{Vector3f(-4.0f, -4.0f, -4.0f), Vector3f(2.0f, 0.0f, -2.0f), Vector3f(0.0f, 0.0f, 0.0f)};
const std::vector<std::string> regionsAt = atlas.labels_for_positions(points);
// nibabel: inv(affine) maps (-4,-4,-4) to voxel (0,0,0) and (2,0,-2) to voxel (3,2,1)
ok &= expect(atlas.is_loaded() && regionsAt == std::vector<std::string>{"Left-Hippocampus", "Right-Hippocampus", "Unknown"},
             std::format("atlas lookup: {}", BASELIB::join(regionsAt, ", ")));
````
