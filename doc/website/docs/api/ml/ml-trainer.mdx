# MLTrainer

**Namespace:** `MLLIB` &nbsp;·&nbsp; **Library:** Machine Learning Library &nbsp;·&nbsp; **Source:** [`ml/ml_trainer.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/ml/ml_trainer.h)

`#include <ml/ml_trainer.h>`

```cpp
class MLLIB::MLTrainer
```

Launches Python training scripts via [`PythonRunner`](/docs/api/pybridge/python-runner) with automatic venv handling and prerequisite checks.

Training logic (PyTorch, scikit-learn, MNE-Python, …) lives entirely in the .py scripts under `scripts/ml/training/` and runs in a child process; no Python embedding or `libpython` linkage is required. If the configured [`PythonRunnerConfig`](/docs/api/pybridge/python-runner-config) carries a `venv_dir`, the runner creates and updates the venv before each script invocation so dependencies are pinned per training job.

```cpp title="src/examples/ex_ml/main.cpp"
QTemporaryDir dir;
QFile script(dir.filePath("train.py"));
const bool written = script.open(QIODevice::WriteOnly) && script.write("import sys\nprint('trained on', sys.argv[1], 'epochs')\n") > 0;
script.close();
MLTrainer trainer; // runs python3; a venv and pip install are configured via PYBRIDGELIB::PythonRunnerConfig
const PYBRIDGELIB::PythonRunnerResult result = trainer.run(script.fileName().toStdString(), {"5"});
```

### runner()

Access the underlying [PythonRunner](/docs/api/pybridge/python-runner) for callback/config changes.

**Returns:**

- *[PythonRunner](/docs/api/pybridge/python-runner) &* — Reference to the PythonRunner instance.

---

### run(scriptPath, args)

Run a training script.

If the [PythonRunner](/docs/api/pybridge/python-runner) is configured with a venv_dir and package_dir, the venv is created/updated automatically before the script runs.

**Parameters:**

- **scriptPath** : *const std::filesystem::path &*
  Path to the .py training script.

- **args** : *const BASELIB::StringList &*
  Arguments forwarded to the script.

**Returns:**

- *[PythonRunnerResult](/docs/api/pybridge/python-runner-result)* — PythonRunnerResult with exit code, output, and progress.

---

### check_prerequisites(packages)

Check that the required Python packages are importable.

**Parameters:**

- **packages** : *const BASELIB::StringList &*
  List of package names (e.g. \{"torch", "mne"\}).

**Returns:**

- *BASELIB::StringList* — List of packages that could NOT be imported (empty = all OK).

````cpp title="src/examples/ex_ml/main.cpp, line 105"
QFile script(dir.filePath("train.py"));
const bool written = script.open(QIODevice::WriteOnly) && script.write("import sys\nprint('trained on', sys.argv[1], 'epochs')\n") > 0;
script.close();
MLTrainer trainer; // runs python3; a venv and pip install are configured via PYBRIDGELIB::PythonRunnerConfig
const PYBRIDGELIB::PythonRunnerResult result = trainer.run(script.fileName().toStdString(), {"5"});
if (trainer.runner().is_python_available()) {
    ok &= expect(written && result.success && result.std_out == "trained on 5 epochs" && trainer.check_prerequisites({"json", "no_such_package_xyz"}) == BASELIB::StringList{"no_such_package_xyz"},
                 "MLTrainer runs the script with its arguments and reports the missing package");
} else {
    std::println("  skip  MLTrainer (python3 not found)");
}
````
