# MNEDescriptionParser

**Namespace:** `MNELIB` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_description_parser.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/mne_description_parser.h)

`#include <mne/mne_description_parser.h>`

```cpp
class MNELIB::MNEDescriptionParser
```

Parses MNE-C style averaging (.ave) and covariance (.cov) description files.

File format is a keyword-value text format with nested blocks: average \{ ... category \{ ... \} ... \} cov \{ ... def \{ ... \} ... \}

Lines starting with '#' are comments.

```cpp title="src/examples/ex_mne_api/main.cpp"
// An MNE-C averaging description (mne_process_raw --ave), parsed and run on the raw recording
const QString aveDesc = tmp.filePath("audvis.ave");
QFile descFile(aveDesc);
ok &= descFile.open(QIODevice::WriteOnly | QIODevice::Text);
descFile.write("average {\n"
               "    category {\n"
               "        name   \"Left Auditory\"\n"
               "        event  1\n"
               "        tmin   -0.1\n"
               "        tmax   0.3\n"
               "        bmin   -0.1\n"
               "        bmax   0.0\n"
               "    }\n"
               "}\n");
descFile.close();
const std::optional<AverageDescription> averaging = MNEDescriptionParser::read_average(aveDesc.toStdU16String());
const AverageCategory& leftCategory = averaging->categories.front(); // name, events, tmin/tmax, baseline
const RejectionParams& rejection = averaging->rej;                   // MNE-C defaults unless the file sets them (EEG 100 uV, ...)
std::string log;
const FiffEvokedSet averages = FiffEvokedSet::computeAverages(raw, *averaging, events.events, log);
```

## Static Methods

### read_average(path)

Reads an averaging description file.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The .ave file.

**Returns:**

- *std::optional&lt; [AverageDescription](/docs/api/fiff/average-description) &gt;* — The description, or no value if the file cannot be read or is malformed.

---

### read_covariance(path)

Reads a covariance description file.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The .cov file.

**Returns:**

- *std::optional&lt; [CovDescription](/docs/api/mne/cov-description) &gt;* — The description, or no value if the file cannot be read or is malformed.
