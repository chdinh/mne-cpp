# MNEBem

**Namespace:** `MNELIB` &nbsp;·&nbsp; **Library:** MNE Library &nbsp;·&nbsp; **Source:** [`mne/mne_bem.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/mne/mne_bem.h)

:::info[Python equivalent]
`mne.make_bem_model` in MNE-Python.
:::

`#include <mne/mne_bem.h>`

```cpp
class MNELIB::MNEBem
```

Boundary element model: aggregates the inner-skull, outer-skull and scalp [`MNEBemSurface`](/docs/api/mne/mne-bem-surface) objects of a head conductor model.

Aggregated boundary element model loaded from a `-bem.fif` file.

```cpp title="src/examples/ex_mne_api/main.cpp"
const QString bemPath = data + "/subjects/sample/bem/sample-5120-bem.fif";
MNEBem bem(bemPath.toStdU16String()); // one MNEBemSurface per BEM layer
const MNEBemSurface& innerSkull = bem[0];
```

## Static Methods

### read(path, patch_stats)

Reads the BEM surfaces of a file, as mne.read_bem_surfaces does.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The -bem.fif file.

- **patch_stats** : *bool*
  Recompute the vertex normals from the triangles even where the file stores them.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; [MNEBem](/docs/api/mne/mne-bem) &gt;* — The model, or why the file cannot be read: Io if it cannot be opened, NotFound if it holds no BEM surfaces, Format if a surface is incomplete or inconsistent.

---

### read(stream, patch_stats)

Reads the BEM surfaces from an open FIFF stream.

**Parameters:**

- **stream** : *[FiffStream](/docs/api/fiff/fiff-stream) &*
  The stream; opened here if it is not open yet.

- **patch_stats** : *bool*
  Recompute the vertex normals from the triangles even where the file stores them.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; [MNEBem](/docs/api/mne/mne-bem) &gt;* — The model, or why the stream cannot be read (see read(path)).

### [ex_mne_api](../../examples/fs/ex_mne_api.mdx)

MNE library: BEM surfaces, surface projection, ICP, source spaces and epochs.

````cpp title="src/examples/ex_mne_api/main.cpp, line 149"
const QString bemPath = data + "/subjects/sample/bem/sample-5120-bem.fif";
MNEBem bem(bemPath.toStdU16String()); // one MNEBemSurface per BEM layer
const MNEBemSurface& innerSkull = bem[0];
// mne.read_bem_surfaces: 1 surface, id 1 (inner skull), 2562 vertices, 5120 triangles
ok &= expect(bem.size() == 1 && innerSkull.id == FIFFV_BEM_SURF_ID_BRAIN && innerSkull.np == 2562 && innerSkull.ntri == 5120 && (innerSkull.rr.row(0) - RowVector3f(0.0006128f, -0.007984f, 0.103732f)).norm() < 1e-6f && (innerSkull.nn.row(0) - RowVector3f(0.05623665f, -0.1050898f, 0.99287134f)).norm() < 1e-5f && MNEBemSurface::id_name(innerSkull.id) == "Brain",
             "MNEBem/MNEBemSurface: inner skull with 2562 vertices and normals like mne.read_bem_surfaces");
````
