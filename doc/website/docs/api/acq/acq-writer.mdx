# AcqWriter

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_stream.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/acq_stream.h)

`#include <acq/acq_stream.h>`

```cpp
class ACQLIB::AcqWriter
```

The single producer of a ring: the backend for an input stream, the application for an output stream.

Move-only. All members except `create()` and `updateInfo()` are allocation-free and lock-free; on input streams they are also wait-free.

Producing an input block, scheduling an output pulse at an exact sample, and driving a card that writes into the ring by DMA: 
```cpp title="src/examples/ex_acq_performance/main.cpp"
auto view = input.beginWrite(kBlock);
std::uint64_t s = view->firstSample();
for (std::size_t p = 0; p < view->partCount(); ++p) {
    const AcqWritePart& part = view->part(p);
    for (std::size_t i = 0; i < part.samples; ++i, ++s) {
        auto* frame = reinterpret_cast<std::int16_t*>(part.at(0, i));
        for (std::size_t c = 0; c < kChannels; ++c) {
            frame[c] = gen.value(s, c);
        }
        if (SignalGenerator::isSpikeStart(s)) {
            AcqEvent marker;
            marker.sample = s;
            marker.duration = kSpikeWidth;
            marker.code = 1;
            input.pushEvent(marker);
            st.spikesInjected.fetch_add(1, std::memory_order_relaxed);
        }
    }
}
st.commitNs[k % kCommitSlots].store(nowNs(), std::memory_order_relaxed);
input.commit(kBlock);
```

### beginWrite(samples, timeout)

Reserves the next `samples` samples.

Input streams never wait. Output streams wait up to `timeout` for the gating reader to free space; if the device has already passed `writePosition()`, the view starts at the device position and reports the gap in `AcqWriteView::underrun()`.

**Parameters:**

- **samples** : *std::size_t*
  Samples per channel.

- **timeout** : *std::chrono::nanoseconds*
  Output streams: maximum wait for space.

**Returns:**

- *[AcqExpected](/docs/api/acq/acq-expected)&lt; [AcqWriteView](/docs/api/acq/acq-write-view) &gt;* — The writable view, or Timeout, InvalidParameter (more than the capacity), EndOfStream (the gating reader was destroyed).

---

### beginWriteAt(firstSample, samples, timeout)

Output streams: reserves `samples` samples starting exactly at `firstSample`, for sample-precise playout (an RF pulse at the sample mapped from a receive event).

Samples between `writePosition()` and `firstSample` are filled with the stream's `AcqUnderrunFill` on commit; they are scheduled silence, not underrun.

**Parameters:**

- **firstSample** : *std::uint64_t*
  Absolute sample index.

- **samples** : *std::size_t*
  Samples per channel.

- **timeout** : *std::chrono::nanoseconds*
  Maximum wait for space.

**Returns:**

- *[AcqExpected](/docs/api/acq/acq-expected)&lt; [AcqWriteView](/docs/api/acq/acq-write-view) &gt;* — The view at `firstSample`, or Late (already played; takes precedence), Timeout, InvalidParameter (before `writePosition()`), NotOnGrid (not a multiple of timebase().sampleAlignment), WrongDirection (input stream).

---

### grant(samples)

Input streams written by a device (DMA): allows the device to write the next `samples` samples after those already granted, directly into the ring.

From now on the device may overwrite anything older than the granted end minus the capacity, so readers count those samples as lost; `commit()` publishes granted samples as the device reports them written. Keep several blocks granted so the device never stalls; do not also `beginWrite()` the granted samples.

**Parameters:**

- **samples** : *std::size_t*
  Samples per channel.

**Returns:**

- *[AcqError](/docs/api/acq/acq-error)* — InvalidParameter if more than the capacity would be granted beyond `writePosition()`, WrongDirection for output streams (there the device is the gating reader).

---

### commit(samples)

Publishes the first samples of the last view (one release store); without a view, the next granted samples.

**Parameters:**

- **samples** : *std::size_t*
  Samples per channel.

---

### pushEvent(event)

Attaches `event` (absolute sample index, not decreasing), published with the next commit (input) or immediately (output; scheduled events may lie ahead of `writePosition()`).

Old events are overwritten like samples; lagging readers count them in `AcqReaderStats::eventsLost`.

**Parameters:**

- **event** : *const [AcqEvent](/docs/api/acq/acq-event) &*
  The event.

**Returns:**

- *[AcqError](/docs/api/acq/acq-error)* — Late for an output event before `devicePosition()`, InvalidParameter for a sample index below the previous event's; otherwise success.

---

### pushSegment(header, payload)

Starts a segment at header.firstSample with its device-specific `payload` (truncated or zero-padded to `AcqSegmentation::headerBytes`); published like events.

**Parameters:**

- **header** : *const [AcqSegmentHeader](/docs/api/acq/acq-segment-header) &*
  Generic segment header.

- **payload** : *std::span&lt; const std::byte &gt;*
  Device-specific header payload.

**Returns:**

- *[AcqError](/docs/api/acq/acq-error)* — Late for an output segment before `devicePosition()`, InvalidParameter for a decreasing firstSample; otherwise success.

---

### updateInfo(info, fromSample)

Publishes a new metadata version, current + 1 (allocates; rare changes only).

**Parameters:**

- **info** : *[AcqStreamInfo](/docs/api/acq/acq-stream-info)*
  New description; channel count, format, layout and direction must not change.

- **fromSample** : *std::uint64_t*
  First sample it describes.

**Returns:**

- *[AcqError](/docs/api/acq/acq-error)* — InvalidParameter for a geometry change or a past sample, InvalidState after too many versions.

---

### finish()

Marks the end of the stream; readers drain and then receive EndOfStream.

Idempotent.
