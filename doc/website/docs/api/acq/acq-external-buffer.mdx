# AcqExternalBuffer

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_stream.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/acq_stream.h)

`#include <acq/acq_stream.h>`

```cpp
struct ACQLIB::AcqExternalBuffer
```

An externally owned buffer adopted as the ring (zero-copy DMA).

Its capacity in samples must be a power of two and its start aligned to 4096 bytes; `release` is called once the ring no longer uses it.

---

## Example

No example of its own: Zero-copy DMA buffer adopted through AcqStreamOptions by a device backend, never by application code.
