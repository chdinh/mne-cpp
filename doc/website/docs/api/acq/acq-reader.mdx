# AcqReader

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_reader.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/acq_reader.h)

`#include <acq/acq_reader.h>`

```cpp
class ACQLIB::AcqReader
```

A consumer of one [`AcqStream`](/docs/api/acq/acq-stream).

Move-only; destroying it frees its reader slot.

```cpp title="src/examples/ex_acq_performance/main.cpp"
auto view = reader.acquire(kBlock, 100ms);
if (!view) {
    if (view.error() == AcqErrorCode::EndOfStream) {
        break;
    }
    continue;
}
```

### acquire(minSamples, timeout, maxSamples)

Waits until at least `minSamples` are available (Latest: the newest `minSamples`), then returns a view of up to `maxSamples`.

Larger blocks amortise the per-view cost; pass maxSamples = 0 to take everything available. One view per reader at a time.

**Parameters:**

- **minSamples** : *std::size_t*
  Samples per channel required; 0 returns immediately (device polling).

- **timeout** : *std::chrono::nanoseconds*
  Maximum wait.

- **maxSamples** : *std::size_t*
  Upper bound of the view, 0 for everything available.

**Returns:**

- *[AcqExpected](/docs/api/acq/acq-expected)&lt; [AcqBlockView](/docs/api/acq/acq-block-view) &gt;* — The view, or Timeout, EndOfStream, DeviceStopped, InvalidState (a view is already held).

---

### release(view)

Returns `view` to the ring and advances the reader; clears `view`.

**Parameters:**

- **view** : *[AcqBlockView](/docs/api/acq/acq-block-view) &*
  A view returned by this reader's `acquire()`.

**Returns:**

- *[AcqError](/docs/api/acq/acq-error)* — Success, or Overrun when the producer overwrote part of the view while it was held; its samples count as lost and anything computed from them must be discarded.

---

### lease(minSamples, timeout, maxSamples)

`acquire()` whose view is released when the returned lease goes out of scope, so no exit path can leave the reader blocked.

Call `AcqViewLease::release()` to learn whether the view was overrun.

**Parameters:**

- **minSamples** : *std::size_t*
  As for `acquire()`.

- **timeout** : *std::chrono::nanoseconds*
  As for `acquire()`.

- **maxSamples** : *std::size_t*
  As for `acquire()`.

**Returns:**

- *[AcqExpected](/docs/api/acq/acq-expected)&lt; [AcqViewLease](/docs/api/acq/acq-view-lease) &gt;* — The lease, or the error of `acquire()`.

---

### consumeIdle(samples)

Gating reader of an output stream: the device has emitted `samples` samples of underrun fill because the writer had not committed them.

Advances this reader; the writer learns the gap from `AcqWriteView::underrun()`.

**Parameters:**

- **samples** : *std::size_t*
  Samples played as fill.

**Returns:**

- *[AcqError](/docs/api/acq/acq-error)* — WrongDirection unless this is the gating reader of an output stream.

- **timeout** : *std::chrono::nanoseconds*
