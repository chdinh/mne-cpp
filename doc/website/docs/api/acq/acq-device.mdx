# AcqDevice

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_device.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/acq_device.h)

`#include <acq/acq_device.h>`

```cpp
class ACQLIB::AcqDevice
```

An opened source.

Move-only handle that owns its backend.

```cpp title="src/examples/ex_acq_oddball/main.cpp"
auto device = AcqDevice::open(uri);
if (!device) {
    std::fprintf(stderr, "Cannot open %s: %s\n", uri.c_str(), device.error().text().c_str());
    return 1;
}
const AcqStream stream = device->stream();
const auto info = stream.info();
// Electrode check before recording; amplifiers without an impedance mode return NotSupported.
if (auto impedances = device->measureImpedances()) {
    for (const AcqImpedance& z : *impedances) {
        if (z.ohms > kMaxImpedanceOhms) {
            std::printf("  check electrode %s: %.0f kOhm\n",
                        device->stream(z.stream).info()->channels[z.channel].name.c_str(), z.ohms * 1e-3);
        }
    }
} else if (impedances.error() != AcqErrorCode::NotSupported) {
    std::fprintf(stderr, "Impedance check failed: %s\n", impedances.error().text().c_str());
}
auto reader = stream.reader(AcqReader::ReadMode::Lossless);
if (!reader || !device->start().ok()) {
    std::fprintf(stderr, "Cannot start %s: %s\n", uri.c_str(), device->lastError().text().c_str());
    return 1;
}
```

### measureImpedances(timeout)

Measures the electrode impedances (control path, allocates).

Not while Running: amplifiers inject a test current for it.

**Parameters:**

- **timeout** : *std::chrono::milliseconds*
  Maximum duration of the measurement.

**Returns:**

- *[AcqExpected](/docs/api/acq/acq-expected)&lt; std::vector&lt; [AcqImpedance](/docs/api/acq/acq-impedance) &gt; &gt;* — One entry per electrode channel, or InvalidState (Running, Failed, Closed), NotSupported (the device cannot measure impedances), or the backend's error.

## Static Methods

### open(uri)

Opens a source through [`AcqDeviceRegistry`](/docs/api/acq/acq-device-registry), e.g.

"synthetic://", "fiff:///data/raw.fif?realtime=1".

**Parameters:**

- **uri** : *std::string_view*
  Source URI.

**Returns:**

- *[AcqExpected](/docs/api/acq/acq-expected)&lt; [AcqDevice](/docs/api/acq/acq-device) &gt;* — The opened source, or InvalidUri, UnknownScheme, InvalidParameter, BackendUnavailable, ...

register_polhemus_scheme();

if (!device) {
    std::fprintf(stderr, "Cannot open the digitizer: %s\n", device.error().text().c_str());
    return EXIT_FAILURE;
}

if (!reader || !device->start().ok()) {
    return EXIT_FAILURE;
}
