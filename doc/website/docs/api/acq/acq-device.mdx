# AcqDevice

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_device.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/acq_device.h)

`#include <acq/acq_device.h>`

```cpp
class ACQLIB::AcqDevice
```

An opened source.

Move-only handle that owns its backend.

```cpp title="src/examples/ex_acq_oddball/main.cpp"
auto device = AcqDevice::open(uri);
if (!device) {
    std::fprintf(stderr, "Cannot open %s: %s\n", uri.c_str(), device.error().text().c_str());
    return 1;
}
const AcqStream stream = device->stream();
const auto info = stream.info();
auto reader = stream.reader(AcqReader::ReadMode::Lossless);
if (!reader || !device->start().ok()) {
    std::fprintf(stderr, "Cannot start %s: %s\n", uri.c_str(), device->lastError().text().c_str());
    return 1;
}
```

### [ex_acq_scope](../../examples/acq/ex_acq_scope.mdx)

Live multi-channel, multi-rate scope of a streaming source with a closed-loop stimulator on the same clock.

````cpp title="src/examples/ex_acq_scope/main.cpp, line 602"
auto device = AcqDevice::open(uri);
if (!device) {
    std::fprintf(stderr, "Cannot open %s: %s\n", uri.c_str(), device.error().text().c_str());
    return 1;
}
const auto info = device->stream().info();
if (isComplex(info->format) || info->sfreq <= 0.0) {
    std::fprintf(stderr, "%s needs a regularly sampled real-valued stream\n", uri.c_str());
    return 1;
}
const double sfreq = info->sfreq;
````
