# AcqClockModel

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_clock_model.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/acq_clock_model.h)

`#include <acq/acq_clock_model.h>`

```cpp
struct ACQLIB::AcqClockModel
```

Linear sample-index &lt;-&gt; host-time model.

Trivially copyable; published by the producer through a sequence counter (no lock) and copied into every view.

physicalNs(s) = anchorHostNs + (s - anchorSample) * 1e9 / (sfreq * rateCorrection) - pipelineDelayNs for input streams (the sample was taken earlier than it arrived) and + pipelineDelayNs for output streams (the sample is emitted later than it is handed over). Times are std::chrono::steady_clock ns.
