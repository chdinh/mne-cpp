# AcqStream

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_stream.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/acq_stream.h)

`#include <acq/acq_stream.h>`

```cpp
class ACQLIB::AcqStream
```

Shared handle of a stream.

Cheap to copy; keeps the ring alive, so readers stay valid after the device is closed (they then return EndOfStream).

```cpp title="src/examples/ex_acq_performance/main.cpp"
auto input = AcqWriter::create(inInfo);
auto stimulator = AcqWriter::create(outInfo);
if (!input || !stimulator) {
    std::fprintf(stderr, "%s\n", (!input ? input.error() : stimulator.error()).text().c_str());
    return false;
}
AcqReaderOptions gating;
gating.gating = true;
auto dac = stimulator->stream().reader(AcqReader::ReadMode::Lossless, gating);
auto recorder = input->stream().reader(AcqReader::ReadMode::Lossless);
auto display = input->stream().reader(AcqReader::ReadMode::Latest);
auto controller = input->stream().reader(AcqReader::ReadMode::LowLatency);
```

### [ex_acq_oddball](../../examples/acq/ex_acq_oddball.mdx)

Recover the P300 from a streaming oddball session by trigger-locked averaging.

````cpp title="src/examples/ex_acq_oddball/main.cpp, line 203"
const AcqStream stream = device->stream();
const auto info = stream.info();
// Electrode check before recording; amplifiers without an impedance mode return NotSupported.
if (auto impedances = device->measureImpedances()) {
    for (const AcqImpedance& z : *impedances) {
        if (z.ohms > kMaxImpedanceOhms) {
            std::printf("  check electrode %s: %.0f kOhm\n",
                        device->stream(z.stream).info()->channels[z.channel].name.c_str(), z.ohms * 1e-3);
        }
    }
} else if (impedances.error() != AcqErrorCode::NotSupported) {
    std::fprintf(stderr, "Impedance check failed: %s\n", impedances.error().text().c_str());
}
auto reader = stream.reader(AcqReader::ReadMode::Lossless);
````
