### start()

Starts acquisition and output.

Called in state Opened or Stopped.

- *[AcqError](/docs/api/acq/acq-error)* — Success, or the error that prevented the start.

---

### stop()

Stops and joins every backend thread before returning.

Called in state Running.

---

### close()

Releases the device.

Called once, after `stop()`. The default does nothing.

---

### measureImpedances(timeout)

Measures electrode impedances.

Called in state Opened or Stopped; the default returns NotSupported.

**Parameters:**

- **timeout** : *std::chrono::milliseconds*
  Maximum duration of the measurement.

**Returns:**

- *[AcqExpected](/docs/api/acq/acq-expected)&lt; std::vector&lt; [AcqImpedance](/docs/api/acq/acq-impedance) &gt; &gt;* — One entry per measured electrode, or the error.

---

## Example

No example of its own: Base class of device drivers; applications reach a backend only through AcqDevice::open().

It is exercised by:

````cpp title="src/examples/ex_acq_oddball/main.cpp"
auto device = AcqDevice::open(uri);
if (!device) {
    std::fprintf(stderr, "Cannot open %s: %s\n", uri.c_str(), device.error().text().c_str());
    return 1;
}
const AcqStream stream = device->stream();
const auto info = stream.info();
// Electrode check before recording; amplifiers without an impedance mode return NotSupported.
if (auto impedances = device->measureImpedances()) {
    for (const AcqImpedance& z : *impedances) {
        if (z.ohms > kMaxImpedanceOhms) {
            std::printf("  check electrode %s: %.0f kOhm\n",
                        device->stream(z.stream).info()->channels[z.channel].name.c_str(), z.ohms * 1e-3);
        }
    }
} else if (impedances.error() != AcqErrorCode::NotSupported) {
    std::fprintf(stderr, "Impedance check failed: %s\n", impedances.error().text().c_str());
}
auto reader = stream.reader(AcqReader::ReadMode::Lossless);
if (!reader || !device->start().ok()) {
    std::fprintf(stderr, "Cannot start %s: %s\n", uri.c_str(), device->lastError().text().c_str());
    return 1;
}
````
