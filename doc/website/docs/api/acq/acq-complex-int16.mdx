# AcqComplexInt16

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_sample_format.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/acq_sample_format.h)

`#include <acq/acq_sample_format.h>`

```cpp
struct ACQLIB::AcqComplexInt16
```

I/Q sample of two signed 16-bit integers, real part first.

std::complex is only specified for floating-point types, hence this type.

## Example

No example of its own: Element type for typed access to ComplexInt16 I/Q samples; a plain value with no behaviour to demonstrate.
