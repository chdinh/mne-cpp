# AcquiredPoints

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/devices/polhemus/acquired_points.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/devices/polhemus/acquired_points.h)

`#include <acq/acquired_points.h>`

```cpp
class ACQLIB::AcquiredPoints
```

In-memory store of all points captured during a session.

The wizard hands one of these to the 3-D view (for visualisation) and later to the export step (for FIFF write). Single-threaded, no locking.

```cpp title="src/examples/ex_acq_polhemus/main.cpp"
AcquiredPoints points;
points.append({PointKind::HeadShape, "HSP-1", 1, Eigen::Vector3f(0.0f, 0.08f, 0.05f)});
points.append({PointKind::Eeg, "Cz", 1, Eigen::Vector3f(0.0f, 0.0f, 0.09f)});
points.undoLast(PointKind::HeadShape);
const DigitizedPoint& kept = points.points().first(); // kind, label, FIFF ident, position (m)
```

Polhemus digitiser: stream stylus poses, register fiducials captured with the button, collect points.

````cpp title="src/examples/ex_acq_polhemus/main.cpp, line 118"
AcquiredPoints points;
points.append({PointKind::HeadShape, "HSP-1", 1, Eigen::Vector3f(0.0f, 0.08f, 0.05f)});
points.append({PointKind::Eeg, "Cz", 1, Eigen::Vector3f(0.0f, 0.0f, 0.09f)});
points.undoLast(PointKind::HeadShape);
const DigitizedPoint& kept = points.points().first(); // kind, label, FIFF ident, position (m)
ok &= expect(points.points().size() == 1 && kept.label == "Cz" && kept.position.z() == 0.09f && points.countOf(PointKind::Eeg) == 1 && !points.hasAllFiducials(),
             "AcquiredPoints keeps Cz after undoing the head-shape point");
````
