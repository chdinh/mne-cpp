# AcqExpected

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_error.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/acq_error.h)

`#include <acq/acq_error.h>`

```cpp
template <typename T>
class ACQLIB::AcqExpected
```

Value-or-error result, the subset of C++23 std::expected that `ACQLIB` needs, without exceptions: accessing the wrong alternative is a precondition violation (assert), never a throw.

```cpp title="src/examples/ex_acq_performance/main.cpp"
auto view = reader.acquire(kBlock, 100ms);
if (!view) {
    if (view.error() == AcqErrorCode::EndOfStream) {
        break;
    }
    continue;
}
```
