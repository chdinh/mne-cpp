# AcqStreamInfo

**Namespace:** `ACQLIB` &nbsp;·&nbsp; **Library:** Acquisition Library &nbsp;·&nbsp; **Source:** [`acq/acq_stream_info.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/acq/acq_stream_info.h)

`#include <acq/acq_stream_info.h>`

```cpp
struct ACQLIB::AcqStreamInfo
```

Complete description of one stream at one metadata version.

```cpp title="src/examples/ex_acq_performance/main.cpp"
AcqStreamInfo inInfo;
inInfo.name = "neural";
inInfo.format = AcqSampleFormat::Int16;
inInfo.sfreq = kSfreq;
inInfo.channels.resize(kChannels);
for (std::size_t c = 0; c < kChannels; ++c) {
    inInfo.channels[c].name = "e" + std::to_string(c);
    inInfo.channels[c].kind = AcqChannelKind::Seeg;
    inInfo.channels[c].unit = AcqUnit::Volt;
    inInfo.channels[c].scale = 0.195e-6;
}
```
