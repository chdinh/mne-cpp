## Static Methods

### readFilter(path, filter)

Reads a given txt file and scans it for filter coefficients.

Pls see sample file for file syntax.

**Parameters:**

- **path** : *QString*
  holds the file path of the txt file which is to be read.

- **filter** : *[FilterKernel](/docs/api/dsp/filter-kernel) &*
  holds the filter which the read parameters are to be saved to.

**Returns:**

- *bool* — true if reading was successful, false otherwise.

---

### writeFilter(path, filter)

Writes a given filter to txt file .

**Parameters:**

- **path** : *const QString &*
  holds the file path of the txt file which is to be written to.

- **filter** : *const [FilterKernel](/docs/api/dsp/filter-kernel) &*
  holds the filter which is to be written to file.

**Returns:**

- *bool* — true if reading was successful, false otherwise.

````cpp title="src/examples/ex_dsp_filter/main.cpp, line 176"
QTemporaryDir dir;
const QString path = dir.filePath("lp40.txt");
FilterKernel reloaded;
const bool written = FilterIO::writeFilter(path, lowPass);
const bool read = FilterIO::readFilter(path, reloaded);
const double ioErr = (reloaded.getCoefficients() - lowPass.getCoefficients()).cwiseAbs().maxCoeff();
ok &= expect(written && read && reloaded.getCoefficients().size() == lowPass.getCoefficients().size() && ioErr < 1e-6,
             std::format("FilterIO round trip keeps {} taps (max error {:g})", reloaded.getCoefficients().size(), ioErr));
````
