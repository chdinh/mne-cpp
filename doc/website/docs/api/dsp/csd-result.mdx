# CsdResult

**Namespace:** `DSPLIB` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/csd.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/csd.h)

```cpp
struct DSPLIB::CsdResult
```

Result of a Cross-[Spectral](/docs/api/math/spectral) Density computation.

```cpp title="src/examples/ex_dsp_spectral/main.cpp"
MatrixXd twoChannels(2, n);
twoChannels.row(0) = signal;
for (int t = 0; t < n; ++t) {
    twoChannels(1, t) = std::cos(2.0 * kPi * 20.0 * t / kSFreq); // 20 Hz, 90 degrees ahead of channel 0
}
const CsdResult csd = Csd::computeMultitaper(twoChannels, kSFreq, 18.0, 22.0, 2.0);
const std::complex<double> cross = csd.matCsd(0, 1);
```
