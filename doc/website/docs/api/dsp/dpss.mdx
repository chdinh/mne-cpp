# Dpss

**Namespace:** `DSPLIB` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/dpss.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/dpss.h)

`#include <dsp/dpss.h>`

```cpp
class DSPLIB::Dpss
```

Discrete Prolate Spheroidal Sequences (Slepian tapers).

Computes DPSS tapers via the tridiagonal eigenvalue formulation. These tapers are used by the multitaper spectral estimator to achieve optimal spectral concentration within a given half-bandwidth.

```cpp title="src/examples/ex_dsp_spectral/main.cpp"
const DpssResult dpss = Dpss::compute(64, 2.5, 4); // N = 64 samples, NW = 2.5, 4 tapers
```

---

## Static Methods

### compute(nSamples, halfBandwidth, nTapers, sym, lowBias)

Compute DPSS tapers for a given window length and half-bandwidth.

**Parameters:**

- **nSamples** : *int*
  Window length N in samples.

- **halfBandwidth** : *double*
  Half-bandwidth parameter (NW); typical values: 2, 3, 4.

- **nTapers** : *int*
  Number of tapers to return; -1 → floor(2*halfBandwidth - 1).

- **sym** : *bool*
  false: periodic tapers for spectral analysis, i.e. the first N samples of the length N + 1 tapers (scipy dpss sym=False, used by MNE-Python).

- **lowBias** : *bool*
  Keep only tapers with concentration &gt; 0.9, at least the first (MNE-Python low_bias).

**Returns:**

- *[DpssResult](/docs/api/dsp/dpss-result)* — [`DpssResult`](/docs/api/dsp/dpss-result) with matTapers (nTapers × N) and vecEigenvalues.

````cpp title="src/examples/ex_dsp_spectral/main.cpp, line 132"
const DpssResult dpss = Dpss::compute(64, 2.5, 4); // N = 64 samples, NW = 2.5, 4 tapers
// scipy.signal.windows.dpss(64, 2.5, 4, return_ratios=True)
const double dpssErr = maxError(dpss.vecEigenvalues, {0.9999972774351693, 0.9998465484588153, 0.9962668597877571, 0.9524259615013084});
ok &= expect(dpss.matTapers.rows() == 4 && dpssErr < 1e-8, std::format("DPSS concentration ratios = scipy (max error {:g})", dpssErr));
ok &= expect((dpss.matTapers * dpss.matTapers.transpose() - MatrixXd::Identity(4, 4)).cwiseAbs().maxCoeff() < 1e-10,
             "DPSS tapers are orthonormal");
````
