# IirStreamFilter

**Namespace:** `DSPLIB` &nbsp;·&nbsp; **Library:** DSP Library &nbsp;·&nbsp; **Source:** [`dsp/iirfilter.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/dsp/iirfilter.h)

:::info[Python equivalent]
[`scipy.signal.sosfilt with zi`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfilt.html) in MNE-Python.
:::

`#include <dsp/iirfilter.h>`

```cpp
class DSPLIB::IirStreamFilter
```

Causal second-order-section filter that keeps its state between blocks.

For filtering acquired data block by block (e.g. decoded from an `ACQLIB` view): the output over any split into blocks is bit-identical to `IirFilter::applySos()` over the whole recording, so online and offline results agree exactly. One state per channel and section, allocated once.

```cpp title="src/examples/ex_dsp_spectral/main.cpp"
// Online: the same low-pass, causal, applied to blocks as they arrive (e.g. from an acquisition stream).
IirStreamFilter online(sos, 1);
MatrixXd stream = signal;
for (Index at = 0; at < stream.cols(); at += 37) {
    online.process(stream.middleCols(at, std::min<Index>(37, stream.cols() - at)));
}
```

## Public Methods

### IirStreamFilter(sos, channels)

**Parameters:**

- **sos** : *const std::vector&lt; [IirBiquad](/docs/api/dsp/iir-biquad) &gt; &*
  Second-order sections, e.g. from `IirFilter::designButterworth()`; empty passes data through.

- **channels** : *int*
  Rows of every block.

---

### process(block)

Filters `block` (channels x samples) in place, continuing from the previous block.

**Parameters:**

- **block** : *Eigen::Ref&lt; Eigen::MatrixXd &gt;*
  The next samples of every channel.

**Returns:**

- *bool* — false, with block and state unchanged, if block.rows() != `channels()`.

---

### reset()

Returns every channel to rest (zero state), as before the first block.

---

### channels()

**Returns:**

- *int* — Rows expected by `process()`.
