# FiffCoordTrans

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_coord_trans.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_coord_trans.h)

:::info[Python equivalent]
`mne.transforms.Transform` in MNE-Python.
:::

`#include <fiff/fiff_coord_trans.h>`

```cpp
class FIFFLIB::FiffCoordTrans
```

Labelled 4x4 FIFF affine: source frame, destination frame, rotation, translation and cached inverse.

Each transform carries its source (`from`) and destination (`to`) `FIFFV_COORD_*` frame identifiers so the inverse and any chained composition can be type-checked at runtime. The inverse is stored alongside the forward transform because both directions are routinely needed (device→head for head-position tracking, head→MRI for source space registration, etc.).

```cpp title="src/examples/ex_fiff_api/main.cpp"
const std::filesystem::path trans = (dir + "/all-trans.fif").toStdU16String();
const FiffCoordTrans headToMri(trans, FIFFV_COORD_HEAD, FIFFV_COORD_MRI); // throws UTILSLIB::Error if it is missing
const FiffCoordTrans devHead = info.dev_head_t;                           // device -> head, from the measurement info
float r[3] = {0.0f, 0.0f, 0.0f};
FiffCoordTrans::apply_trans(r, devHead, true); // the device origin in head coordinates
```
