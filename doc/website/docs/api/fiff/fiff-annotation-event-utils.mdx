# FiffAnnotationEventUtils

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library

:::info[Module]
This page documents a **header-level module** — a collection of free
functions that share an algorithmic topic. There is no enclosing C++
class; the functions live directly in the library namespace.
:::

:::info[Python equivalent]
`mne.events_from_annotations` in MNE-Python.
:::

`#include <fiff/fiff_annotation_event_utils.h>`

SPDX-License-Identifier: BSD-3-Clause Copyright (c) 2026 MNE-CPP Authors.

Two representations coexist in MNE workflows: free-text [`FiffAnnotation`](/docs/api/fiff/fiff-annotation) entries (onset / duration / description) and integer (sample, prev, code) event triples extracted from a stim channel or fed to `mne.Epochs`. These free functions translate between the two: mapping annotation descriptions to event codes via a description→code table, exploding annotation durations into start / stop event pairs, and the reverse aggregation. They mirror `mne.events_from_annotations` and `mne.annotations_from_events` in MNE-Python.

```cpp title="src/examples/ex_fiff_api/main.cpp"
MatrixXi firstThree = events.events.topRows(3);
FiffAnnotations annotations = annotations_from_events(firstThree, info.sfreq, {{1, "auditory/left"}, {2, "auditory/right"}}, raw.first_samp);
annotations.append(0.5, 1.0, "BAD_blink"); // onset s, duration s, description
const std::filesystem::path csv = tmp.filePath("annot.csv").toStdString();
const bool annotationsWritten = annotations.write(csv).has_value();
const FiffAnnotations annotationsBack = FiffAnnotations::read(csv).value(); // value() throws BASELIB::Error
const MatrixXi eventsAgain = events_from_annotations(annotationsBack.select("auditory"), info.sfreq, {{"auditory/left", 1}, {"auditory/right", 2}}, raw.first_samp);
```

## Functions

### annotations_from_events(events, sfreq, event_desc, first_sample)

```cpp
[FiffAnnotations](/docs/api/fiff/fiff-annotations) annotations_from_events(const Eigen::MatrixXi & events, double sfreq, const std::map< int, std::string > & event_desc, int first_sample);
```

Converts events to annotations, like mne.annotations_from_events.

Each event becomes a point annotation at (sample - first_sample) / sfreq, described by the label of its id (the third column) or, without a label, by the id itself.

**Parameters:**

- **events** : *const Eigen::MatrixXi &*
  Events, one row [sample, before, id] each.

- **sfreq** : *double*
  Sampling frequency in Hz.

- **event_desc** : *const std::map&lt; int, std::string &gt; &*
  Label of each event id.

- **first_sample** : *int*
  First sample of the recording.

**Returns:**

- *[FiffAnnotations](/docs/api/fiff/fiff-annotations)* — One annotation per event; none if `sfreq` is not positive.

### events_from_annotations(annotations, sfreq, event_id, first_sample)

```cpp
Eigen::MatrixXi events_from_annotations(const [FiffAnnotations](/docs/api/fiff/fiff-annotations) & annotations, double sfreq, const std::map< std::string, int, std::less<> > & event_id, int first_sample);
```

Converts annotations to events, like mne.events_from_annotations.

Each annotation becomes a row [sample, 0, id], with the id of its description in `event_id` or, failing that, the description read as an integer, or 0.

**Parameters:**

- **annotations** : *const [FiffAnnotations](/docs/api/fiff/fiff-annotations) &*
  The annotations.

- **sfreq** : *double*
  Sampling frequency in Hz.

- **event_id** : *const std::map&lt; std::string, int, std::less&lt;&gt; &gt; &*
  Id of each description.

- **first_sample** : *int*
  First sample of the recording.

**Returns:**

- *Eigen::MatrixXi* — One event row per annotation; none if `sfreq` is not positive.
