# FiffTag

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_tag.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_tag.h)

`#include <fiff/fiff_tag.h>`

```cpp
class FIFFLIB::FiffTag
```

FIFF tag: 16-byte header (kind, type, size, next) plus payload, with typed decoders for every FIFFT_* type.

Holds the four header fields exactly as stored on disk and the raw payload bytes. Decoders convert the payload to the appropriate C++ representation: scalars via `to_int` / `to_float` / `to_double`, dense and sparse matrices via `to_float_matrix` / `to_sparse_float_matrix`, and the structured FIFF records into their class wrappers (`to_fiff_id`, `to_coord_trans`, `to_ch_info`, `to_dig_point`, `to_dir_entry`, ...). Used by [`FiffStream`](/docs/api/fiff/fiff-stream) both for streaming reads and for assembling tags before write_tag.

```cpp title="src/examples/ex_fiff_api/main.cpp"
FiffStream stream(QString(dir + "/sample_audvis-ave.fif").toStdU16String());
const bool opened = stream.open();
const std::vector<std::shared_ptr<FiffDirNode>> measNodes = stream.dirtree()->dir_tree_find(FIFFB_MEAS_INFO);
const std::optional<FiffTag> nchan = measNodes.front()->find_tag(stream, FIFF_NCHAN); // raw tag access
const FiffId fileId = stream.id();
stream.close();
```

### convert_matrix_from_file_data(tag)

Machine dependent data type conversions (tag info only).

from_endian defines the byte order of the input to_endian defines the byte order of the output

Either of these may be specified as FIFFV_LITTLE_ENDIAN, FIFFV_BIG_ENDIAN, or FIFFV_NATIVE_ENDIAN. The last choice means that the native byte order value will be substituted here before proceeding

**Parameters:**

- **tag** : *[FiffTag](/docs/api/fiff/fiff-tag) &*
  Matrix tag whose dimensions, indices and data are byte-swapped in place; non-matrix tags are left untouched.

FiffStream stream(QString(dir + "/sample_audvis-ave.fif").toStdU16String());
