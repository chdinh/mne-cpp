# FiffDigitizerData

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_digitizer_data.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_digitizer_data.h)

`#include <fiff/fiff_digitizer_data.h>`

```cpp
class FIFFLIB::FiffDigitizerData
```

Registration-ready digitization data: dig points, device→head transform and HPI fit metadata.

Pairs a [`FiffDigPointSet`](/docs/api/fiff/fiff-dig-point-set) with the [`FiffCoordTrans`](/docs/api/fiff/fiff-coord-trans) that maps it into the head frame, plus optional HPI goodness-of-fit values. Used by the coregistration GUI and by every downstream tool that needs a single self-contained record describing where a subject's head sat in the helmet for one measurement.

```cpp title="src/examples/ex_fiff_api/main.cpp"
FiffDigitizerData digData;
digData.points = info.dig;
digData.coord_frame = FIFFV_COORD_HEAD;
digData.head_mri_t_adj = headToMri;
digData.pick_cardinal_fiducials(); // LPA, nasion and RPA moved into MRI coordinates
```

### FiffDigitizerData(path)

Reads the digitizer data of a FIFF file like `read()`; throws [`Error`](/docs/api/utils/error) if it cannot.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The FIFF file.

---

### print()

Prints the number of points, their frame, the HPI coils and the number of MRI fiducials.

---

### nfids()

**Returns:**

- *int* — The number of MRI fiducials, as MNE-C's digitizerDataRec.nfids.

---

### pick_cardinal_fiducials()

Sets mri_fids to the cardinal points moved into MRI coordinates by head_mri_t_adj, as MNE-C's update_fids_from_dig_data (mne_analyze/adjust_alignment.c); clears them without that transform.

---

## Static Methods

### read(path)

Reads the digitizer data of a FIFF file: the points of its isotrak block in head coordinates, or of its MRI set in MRI coordinates.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The FIFF file.

**Returns:**

- *[Expected](/docs/api/utils/expected)&lt; [FiffDigitizerData](/docs/api/fiff/fiff-digitizer-data) &gt;* — The data, or why the file cannot be read: Io if it cannot be opened, NotFound if it holds no digitizer points.
