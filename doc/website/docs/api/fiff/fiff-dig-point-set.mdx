# FiffDigPointSet

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_dig_point_set.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_dig_point_set.h)

`#include <fiff/fiff_dig_point_set.h>`

```cpp
class FIFFLIB::FiffDigPointSet
```

Collection of [`FiffDigPoint`](/docs/api/fiff/fiff-dig-point) records as parsed from a FIFFB_ISOTRAK block.

A contiguous range of points with the container interface of std::vector, plus the selection, transformation and file operations of mne.io.Info["dig"].

```cpp title="src/examples/ex_fiff_api/main.cpp"
const FiffDigPointSet& digitizer = info.dig;                             // 146 points in head coordinates
FiffDigPointSet cardinal = digitizer.pick_types({FIFFV_POINT_CARDINAL}); // LPA, nasion, RPA
```

### readPolhemusIsotrak(path, dig, chNames, unit)

Reads a Polhemus Isotrak digitizer file, as mne.channels.read_dig_polhemus_isotrak does.

The three fiducials become cardinal points (LPA, nasion, RPA). The remaining points become HPI coils for an .elp file and head shape points for .hsp/.eeg files, or EEG electrodes when `chNames` names them. Electrodes are numbered by the last three characters of their names when all of those are numbers, and 1..n otherwise. All points are in digitizer coordinates (FIFFV_COORD_UNKNOWN).

**Parameters:**

- **path** : *const QString &*
  The .elp, .hsp or .eeg file.

- **dig** : *[FiffDigPointSet](/docs/api/fiff/fiff-dig-point-set) &*
  The digitizer points.

- **chNames** : *const QStringList &*
  Electrode names, one per non-fiducial point, or empty.

- **unit** : *const QString &*
  Unit of the file: "m", "cm" or "mm".

**Returns:**

- *bool* — false if the file cannot be read, the extension or unit is unknown, or the number of names does not match the number of points.

### readCaptrak(path, dig, chNames)

Reads a BrainVision CapTrak .bvct file, as mne.channels.read_dig_captrak does.

The electrodes named Nasion, LPA and RPA become the cardinal points, every other electrode an EEG point; millimetres are converted to metres. The points are in digitizer coordinates (FIFFV_COORD_UNKNOWN), numbered as by readPolhemusIsotrak; a repeated name keeps its first place and its last position.

**Parameters:**

- **path** : *const QString &*
  The .bvct file.

- **dig** : *[FiffDigPointSet](/docs/api/fiff/fiff-dig-point-set) &*
  The digitizer points.

- **chNames** : *QStringList **
  If not null, the electrode names in the order of the EEG points.

**Returns:**

- *bool* — false if the file cannot be parsed or lacks one of the fiducials.

---

### readEgi(path, dig, chNames)

Reads the coordinates.xml of an EGI MFF recording, as mne.channels.read_dig_egi does.

Sensors of type 0 become EEG points named "EEG &lt;number&gt;", the reference (type 1) is numbered after the electrodes before it, and the nasion and periauricular points (type 2) become the cardinal points. Unlike mne.channels.read_dig_egi, which keeps the file's centimetres as if they were metres, the positions are converted to metres (as mne.io.read_raw_egi does).

**Parameters:**

- **path** : *const QString &*
  The coordinates.xml file.

- **dig** : *[FiffDigPointSet](/docs/api/fiff/fiff-dig-point-set) &*
  The digitizer points, in digitizer coordinates.

- **chNames** : *QStringList **
  If not null, the electrode names in the order of the EEG points.

**Returns:**

- *bool* — false if the file cannot be parsed or lacks one of the fiducials.

### readNeuroscanDat(path, dig, chNames)

Reads a Neuroscan .dat electrode file ("name number x y z" per line), as mne.channels.read_dig_dat does: point numbers 78, 76 and 82 are the nasion, LPA and RPA, 67 (the centroid) is skipped, and the coordinates are kept as they are.

**Parameters:**

- **path** : *const QString &*
  The .dat file.

- **dig** : *[FiffDigPointSet](/docs/api/fiff/fiff-dig-point-set) &*
  The digitizer points, in digitizer coordinates.

- **chNames** : *QStringList **
  If not null, the electrode names in the order of the EEG points.

**Returns:**

- *bool* — false if the file cannot be read or a line does not hold five entries.
