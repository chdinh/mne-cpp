# FiffFileSharer

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_file_sharer.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_file_sharer.h)

`#include <fiff/fiff_file_sharer.h>`

```cpp
class FIFFLIB::FiffFileSharer
```

Copies FIFF recordings into a shared directory and lists the ones a consumer has not seen yet.

```cpp title="src/examples/ex_fiff_structure/main.cpp"
// Hand a finished recording to another application through a shared directory.
const std::filesystem::path shared = std::filesystem::path(tmp.path().toStdU16String()) / "shared";
FiffFileSharer consumer(shared);
consumer.clear();
FiffFileSharer producer(shared);
producer.copy_realtime_file(rawPath.toStdU16String()).value();           // shared/realtime_file0_raw.fif
const std::vector<std::filesystem::path> arrived = consumer.new_files(); // call it when a watcher reports a change
```

## Public Methods

### FiffFileSharer(directory)

**Parameters:**

- **directory** : *const std::filesystem::path &*

---

### directory()

**Returns:**

- *const std::filesystem::path &* — The shared directory, absolute.

---

### copy_realtime_file(source)

Producer: copies an unfinished FIFF recording into the shared directory and closes its raw block.

The copy appears under its name only once it is complete.

**Parameters:**

- **source** : *const std::filesystem::path &*
  The recording, still being written.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; std::filesystem::path &gt;* — The shared file, or an Io error if the directory cannot be made or the source cannot be copied.

---

### new_files()

Consumer: the files shared since the last call, in the order they were shared.

**Returns:**

- *std::vector&lt; std::filesystem::path &gt;* — Paths of complete FIFF files.

---

### clear()

Consumer: creates the shared directory if needed, removes the files of earlier sessions and starts counting from the first file again.

**Returns:**

- *bool* — Whether the directory exists and is empty.

````cpp title="src/examples/ex_fiff_structure/main.cpp, line 148"
// Hand a finished recording to another application through a shared directory.
const std::filesystem::path shared = std::filesystem::path(tmp.path().toStdU16String()) / "shared";
FiffFileSharer consumer(shared);
consumer.clear();
FiffFileSharer producer(shared);
producer.copy_realtime_file(rawPath.toStdU16String()).value();           // shared/realtime_file0_raw.fif
const std::vector<std::filesystem::path> arrived = consumer.new_files(); // call it when a watcher reports a change
const FiffRawData sharedRaw(arrived.empty() ? shared : arrived.front());
ok &= expect(arrived.size() == 1 && sharedRaw.last_samp - sharedRaw.first_samp + 1 == 6007,
             "FiffFileSharer: the consumer gets the shared recording and it reads back with all 6007 samples");
````
