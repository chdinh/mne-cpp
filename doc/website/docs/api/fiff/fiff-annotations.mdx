# FiffAnnotations

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_annotations.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_annotations.h)

:::info[Python equivalent]
`mne.Annotations` in MNE-Python.
:::

`#include <fiff/fiff_annotations.h>`

```cpp
class FIFFLIB::FiffAnnotations
```

Container for [`FiffAnnotation`](/docs/api/fiff/fiff-annotation) entries with FIFF, JSON and CSV serializers.

Read and written under `FIFFB_MNE_ANNOTATIONS` by `FiffStream::read_annotations()` and `FiffStream::write_annotations()`, so the annotation list travels with the FIFF file. The JSON and CSV files let the same annotations be consumed by BIDS sidecars and by external scoring tools that do not understand FIFF.

```cpp title="src/examples/ex_fiff_api/main.cpp"
MatrixXi firstThree = events.events.topRows(3);
FiffAnnotations annotations = annotations_from_events(firstThree, info.sfreq, {{1, "auditory/left"}, {2, "auditory/right"}}, raw.first_samp);
annotations.append(0.5, 1.0, "BAD_blink"); // onset s, duration s, description
const std::filesystem::path csv = tmp.filePath("annot.csv").toStdString();
const bool annotationsWritten = annotations.write(csv).has_value();
const FiffAnnotations annotationsBack = FiffAnnotations::read(csv).value(); // value() throws BASELIB::Error
const MatrixXi eventsAgain = events_from_annotations(annotationsBack.select("auditory"), info.sfreq, {{"auditory/left", 1}, {"auditory/right", 2}}, raw.first_samp);
```

### [ex_fiff_api](../../examples/fiff/ex_fiff_api.mdx)

FIFF library: measurement info, channels, digitizer, transforms, projectors, covariance, events, annotations, evoked sets and the low-level file structure.

````cpp title="src/examples/ex_fiff_api/main.cpp, line 205"
MatrixXi firstThree = events.events.topRows(3);
FiffAnnotations annotations = annotations_from_events(firstThree, info.sfreq, {{1, "auditory/left"}, {2, "auditory/right"}}, raw.first_samp);
annotations.append(0.5, 1.0, "BAD_blink"); // onset s, duration s, description
const std::filesystem::path csv = tmp.filePath("annot.csv").toStdString();
const bool annotationsWritten = annotations.write(csv).has_value();
const FiffAnnotations annotationsBack = FiffAnnotations::read(csv).value(); // value() throws BASELIB::Error
const MatrixXi eventsAgain = events_from_annotations(annotationsBack.select("auditory"), info.sfreq, {{"auditory/left", 1}, {"auditory/right", 2}}, raw.first_samp);
// Event 13988 (code 2) is (13988 - 12900) / 300.307 s = 3.6230 s after the first sample; code 3 has no description and stays "3"; the CSV keeps onsets to well within half a sample
ok &= expect(annotationsWritten && annotationsBack.size() == 4 && std::fabs(annotationsBack.select("auditory/right")[0].onset - (13988 - 12900) / info.sfreq) < 0.5 / info.sfreq && eventsAgain.rows() == 2 && eventsAgain(0, 0) == 13988 && eventsAgain(1, 0) == 14385 && eventsAgain(1, 2) == 1 && annotationsBack.select("3").size() == 1,
             "FiffAnnotations: events become onsets in seconds and back, with descriptions as codes");
````

AnnotateAmplitudeParams amplitude;
