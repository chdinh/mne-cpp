# Fiff

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff.h)

`#include <fiff/fiff.h>`

```cpp
class FIFFLIB::Fiff
```

MATLAB-style static facade re-exporting every public `FIFFLIB` reader/writer for parity with the mne-matlab toolbox.

Only wrappers — no state. Each method forwards to the matching method on [`FiffStream`](/docs/api/fiff/fiff-stream) / [`FiffRawData`](/docs/api/fiff/fiff-raw-data) / [`FiffEvoked`](/docs/api/fiff/fiff-evoked) / [`FiffEvokedSet`](/docs/api/fiff/fiff-evoked-set) / [`FiffCov`](/docs/api/fiff/fiff-cov) / [`FiffInfo`](/docs/api/fiff/fiff-info). Prefer the underlying classes for new code; this class exists so Matlab-style ports compile unchanged.

```cpp title="src/examples/ex_fiff_api/main.cpp"
QFile facadeFile(dir + "/sample_audvis_trunc_raw.fif");
std::unique_ptr<FiffStream> facadeStream;
const bool facadeOpened = Fiff::open(facadeFile, facadeStream); // static wrappers around FiffStream
FiffDirNode::SPtr facadeRoot = facadeStream->dirtree();
const StringList facadeBads = facadeStream->read_bad_channels(facadeRoot);
facadeStream->close();
```
