# FiffIO

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_io.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_io.h)

`#include <fiff/fiff_io.h>`

```cpp
class FIFFLIB::FiffIO
```

One-call FIFF reader/writer: opens a file, dispatches to the right specialized loader and returns ready-to-use `FIFFLIB` containers.

Sniffs the FIFF block tree, dispatches [`FiffRawData`](/docs/api/fiff/fiff-raw-data) / [`FiffEvokedSet`](/docs/api/fiff/fiff-evoked-set) loaders as appropriate, and returns shared pointers so the resulting objects can be freely passed across the rest of the pipeline. Front-end parity with `mne.io.read_raw_fif` and `mne.read_evokeds`.

```cpp title="src/examples/ex_fiff_api/main.cpp"
FiffIO io(QString(dir + "/sample_audvis-ave.fif").toStdU16String()); // detects what the file holds (raw, evoked, fwd, ...)
```

### read(bytes)

Appends the raw data of a FIFF file held in memory; evoked data can only be read from a file.

**Parameters:**

- **bytes** : *std::vector&lt; std::byte &gt;*
  The file contents.

**Returns:**

- *bool* — false if the bytes hold no FIFF directory tree, true otherwise.

---

### write(path, type, idx)

Writes data of one type to a FIFF file.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The file. Raw data sets written all at once go to one file each, named after it with "_raw-&lt;index&gt;" before ".fif"; evoked data sets go to one file together.

- **type** : *fiff_int_t*
  FIFFB_RAW_DATA or FIFFB_EVOKED.

- **idx** : *fiff_int_t*
  Index of the data set, -1 for all.

**Returns:**

- *bool* — true if succeeded, false otherwise.

---

### write_raw(path, idx)

Writes one raw data set to a FIFF file.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The file.

- **idx** : *fiff_int_t*
  Index of the raw data set.

**Returns:**

- *bool* — true if succeeded, false otherwise.
