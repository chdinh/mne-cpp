# FiffEvents

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_events.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_events.h)

`#include <fiff/fiff_events.h>`

```cpp
class FIFFLIB::FiffEvents
```

FIFF event list: (sample, prev, new) integer triples with read / write / detect / filter helpers.

On-disk representation matches `mne.io.write.write_events` output and the `-eve.fif` files consumed by `mne.read_events`; the detection path mirrors `mne.find_events`. Used by [`FiffEpochs`](/docs/api/fiff/fiff-epochs) and the batch-averaging path in [`FiffEvokedSet`](/docs/api/fiff/fiff-evoked-set) to drive epoch extraction.

```cpp title="src/examples/ex_fiff_api/main.cpp"
const FiffEvents events = FiffEvents::find_events(raw, "STI 014").value(); // rising edges, like mne.find_events
const std::string eventPath = tmp.filePath("sample-eve.fif").toStdString();
const bool eventsWritten = events.write(eventPath).has_value();
FiffEvents eventsBack(eventPath); // mne.read_events reads this file too
```

### pick(include, exclude, step)

### find_events(raw, stim_channel, mask, leading_edge)

Finds the trigger events of a stimulus channel, like mne.find_events.

**Parameters:**

- **raw** : *const [FiffRawData](/docs/api/fiff/fiff-raw-data) &*
  The recording.

- **stim_channel** : *std::string_view*
  Name of the stimulus channel; matched as `same_channel()` does ("STI014" finds "STI 014").

- **mask** : *unsigned int*
  Bits of the channel value that count.

- **leading_edge** : *bool*
  Only changes from 0 to a non-zero value, rather than every change.

**Returns:**

- *[Expected](/docs/api/base/expected)&lt; [FiffEvents](/docs/api/fiff/fiff-events) &gt;* — The events, which may be none, or why there are none: NotFound if the channel is missing, Io if its data cannot be read.

### find_stim_steps(stim_data, first_samp, pad_start, pad_stop, merge)

Find the samples where all stimulus channels change at once, like mne.find_stim_steps.

**Parameters:**

- **stim_data** : *const Eigen::MatrixXi &*
  Stimulus channel data (channels x samples); steps carry the values of the first row.

- **first_samp** : *int*
  Sample number of the first column.

- **pad_start** : *std::optional&lt; int &gt;*
  If set, a step from this value at sample 0 is added when the data start elsewhere.

- **pad_stop** : *std::optional&lt; int &gt;*
  If set, a step to this value after the last sample is added.

- **merge** : *int*
  Merge steps at most |merge| samples apart (&gt; 0: into the later, &lt; 0: into the earlier).

**Returns:**

- *[FiffEvents](/docs/api/fiff/fiff-events)* — Steps as [sample, value before, value after].

---

### make_fixed_length(raw, id, start, stop, duration, first_samp, overlap)

Events at regular intervals, like mne.make_fixed_length_events.

**Parameters:**

- **raw** : *const [FiffRawData](/docs/api/fiff/fiff-raw-data) &*
  The recording.

- **id** : *int*
  Event code.

- **start** : *double*
  First event time in s.

- **stop** : *double*
  Time in s after which no event may start (negative: end of the recording).

- **duration** : *double*
  Duration of each segment in s.

- **first_samp** : *bool*
  Whether times count from the recording's first sample (true) or from 0.

- **overlap** : *double*
  Overlap of consecutive segments in s, 0 &lt;= overlap &lt; duration.

**Returns:**

- *[FiffEvents](/docs/api/fiff/fiff-events)* — The events (empty if none fit or the overlap is invalid).

QFile rawFile(data + "/MEG/sample/sample_audvis_trunc_raw.fif");
const FiffRawData raw((data + "/MEG/sample/sample_audvis_trunc_raw.fif").toStdString());
const FiffEvents events = FiffEvents::find_events(raw).value(); // rising edges on STI 014

MNEEpochDataList epochs = MNEEpochDataList::readEpochs(raw, events.events, -0.1f, 0.3f, 1, {});
const MNEEpochData& firstEpoch = *epochs.first();
