# FiffDeviceInfo

**Namespace:** `FIFFLIB` &nbsp;·&nbsp; **Library:** FIFF Library &nbsp;·&nbsp; **Source:** [`fiff/fiff_info.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/fiff/fiff_info.h)

`#include <fiff/fiff_info.h>`

```cpp
struct FIFFLIB::FiffDeviceInfo
```

The acquisition device of a measurement (FIFFB_DEVICE), the counterpart of info["device_info"] in MNE-Python.

```cpp title="src/examples/ex_acq_record/main.cpp"
FiffRawData raw(QString::fromStdString(path).toStdString());
const FiffDeviceInfo& recorded = raw.info.device_info; // backend, device and source id of the recording
std::printf("%s: %d channels, samples %d to %d, device %s '%s' (%s)\n", path.c_str(), raw.info.nchan,
            raw.first_samp, raw.last_samp, recorded.type.c_str(), recorded.model.c_str(),
            recorded.serial.c_str());
```

---

## Public Methods

### isEmpty()

**Returns:**

- *bool* — true when no field is set; then no FIFFB_DEVICE block is written.
