# InvConvenience

**Namespace:** `INVLIB` &nbsp;·&nbsp; **Library:** Inverse Library

:::info[Module]
This page documents a **header-level module** — a collection of free
functions that share an algorithmic topic. There is no enclosing C++
class; the functions live directly in the library namespace.
:::

:::info[Python equivalent]
`mne.minimum_norm.apply_inverse_epochs / apply_inverse_raw / apply_inverse_cov` in MNE-Python.
:::

`#include <inv/inv_convenience.h>`

SPDX-License-Identifier: BSD-3-Clause Copyright (c) 2026 MNE-CPP Authors.

`apply_inverse_*` / `compute_source_psd` helpers.

Free functions in this header glue together the lower-level `INVLIB` classes so users can match the MNE-Python ergonomics: `INVLIB::apply_inverse_epochs` applies a precomputed inverse operator across an epoch list, `apply_inverse_raw` streams raw data through the kernel, `estimate_snr` returns the whitened-data SNR trace from an evoked + inverse pair, `compute_whitener` produces the diagonal whitener from a noise covariance, and `compute_source_psd` / `compute_source_band_power` run Welch-based spectral analysis directly on [`InvSourceEstimate`](/docs/api/inv/inv-source-estimate) output. All methods are headers-only orchestration on top of [`InvMinimumNorm`](/docs/api/inv/inv-minimum-norm) and the underlying FIFF / MNE primitives.

```cpp title="src/examples/ex_inv_api/main.cpp"
// Whitened data and a gain per nAm make the noise level 1, as mne.inverse_sparse.mixed_norm does.
const auto [whitener, rank] = compute_whitener(inverse.noise_cov); // rank 360: 364 channels minus 4 projectors
const MNEForwardSolution fixedFwd = MNEForwardSolution(fwdPath, {.force_fixed = true, .surf_ori = true}).pick_regions({v1}).pick_channels(inverse.noise_cov.names);
const MatrixXd gain = whitener * fixedFwd.sol.data * 1e-9;
const MatrixXd measured = whitener * evoked.pick_channels(inverse.noise_cov.names).data.middleCols(170, 40); // 83-148 ms
const double alphaMax = (gain.transpose() * measured).rowwise().norm().maxCoeff();
const InvMxneResult mxne = InvMxne::compute(gain, measured, 0.5 * alphaMax, 1000, 1e-10);
```

## Functions

### apply_inverse_epochs(epochs, inverse, lambda2, method, tmin, tstep, pickNormal)

```cpp
std::vector< [InvSourceEstimate](/docs/api/inv/inv-source-estimate) > apply_inverse_epochs(const std::vector< Eigen::MatrixXd > & epochs, const [MNEInverseOperator](/docs/api/mne/mne-inverse-operator) & inverse, float lambda2, std::string_view method, float tmin, float tstep, bool pickNormal);
```

Apply inverse operator to each epoch in a list.

For each epoch (data matrix), applies the minimum norm inverse and returns a list of source estimates. This is the equivalent of MNE-Python's mne.minimum_norm.apply_inverse_epochs().

**Parameters:**

- **epochs** : *const std::vector&lt; Eigen::MatrixXd &gt; &*
  List of epoch data matrices (n_channels x n_times each).

- **inverse** : *const [MNEInverseOperator](/docs/api/mne/mne-inverse-operator) &*
  Pre-computed inverse operator.

- **lambda2** : *float*
  Regularization parameter (1/SNR^2).

- **method** : *std::string_view*
  "MNE", "dSPM", or "sLORETA".

- **tmin** : *float*
  Start time of each epoch (seconds).

- **tstep** : *float*
  Time step (1/sfreq).

- **pickNormal** : *bool*
  If true, keep only the normal component.

**Returns:**

- *std::vector&lt; [InvSourceEstimate](/docs/api/inv/inv-source-estimate) &gt;* — List of source estimates, one per epoch.

### apply_inverse_raw(raw, inverse, lambda2, method, from, to, pickNormal)

```cpp
[InvSourceEstimate](/docs/api/inv/inv-source-estimate) apply_inverse_raw(const [FiffRawData](/docs/api/fiff/fiff-raw-data) & raw, const [MNEInverseOperator](/docs/api/mne/mne-inverse-operator) & inverse, float lambda2, std::string_view method, int from, int to, bool pickNormal);
```

Apply inverse operator to raw data.

Reads the requested range and applies the inverse operator with nave = 1. Equivalent of MNE-Python's mne.minimum_norm.apply_inverse_raw(), except that `from` and `to` are absolute sample numbers and the source estimate starts at `from` / sfreq (MNE-Python counts from the first sample).

**Parameters:**

- **raw** : *const [FiffRawData](/docs/api/fiff/fiff-raw-data) &*
  Raw data object.

- **inverse** : *const [MNEInverseOperator](/docs/api/mne/mne-inverse-operator) &*
  Pre-computed inverse operator.

- **lambda2** : *float*
  Regularization parameter (1/SNR^2).

- **method** : *std::string_view*
  "MNE", "dSPM", or "sLORETA".

- **from** : *int*
  First sample to process (default: first_samp).

- **to** : *int*
  Last sample to process (default: last_samp).

- **pickNormal** : *bool*
  If true, keep only the normal component.

**Returns:**

- *[InvSourceEstimate](/docs/api/inv/inv-source-estimate)* — Source estimate spanning the requested time range.

### apply_forward(fwd, stc, info)

```cpp
[FiffEvoked](/docs/api/fiff/fiff-evoked) apply_forward(const [MNEForwardSolution](/docs/api/mne/mne-forward-solution) & fwd, const [InvSourceEstimate](/docs/api/inv/inv-source-estimate) & stc, const [FiffInfo](/docs/api/fiff/fiff-info) & info);
```

Project a source estimate to the sensors, as mne.apply_forward.

A free-orientation forward is first converted to fixed orientation along the (patch-averaged) cortical normals. The source estimate rows are matched to forward columns by vertex number per hemisphere (`stc.nVerticesLh` splits lh and rh); a vertex the forward lacks is an error. A forward without source spaces is used column by column. The evoked carries the forward's channels taken from `info`.

**Parameters:**

- **fwd** : *const [MNEForwardSolution](/docs/api/mne/mne-forward-solution) &*
  Forward solution; its channels must all be in `info`.

- **stc** : *const [InvSourceEstimate](/docs/api/inv/inv-source-estimate) &*
  Source estimate with one row per source.

- **info** : *const [FiffInfo](/docs/api/fiff/fiff-info) &*
  Measurement info supplying the channel descriptions.

**Returns:**

- *[FiffEvoked](/docs/api/fiff/fiff-evoked)* — Simulated evoked data, empty on error.

### estimate_snr(evoked, inverse)

```cpp
std::pair< Eigen::VectorXd, Eigen::VectorXd > estimate_snr(const [FiffEvoked](/docs/api/fiff/fiff-evoked) & evoked, const [MNEInverseOperator](/docs/api/mne/mne-inverse-operator) & inverse);
```

Estimate the SNR of evoked data as a function of time.

Equivalent of MNE-Python's mne.minimum_norm.estimate_snr(): `snr` is the global field power of the whitened data, `snrEst` the largest regularization 1/sqrt(lambda2) whose prediction error passes a chi^2 test at p = 0.001 (0 where `snr` &lt;= 1).

**Parameters:**

- **evoked** : *const [FiffEvoked](/docs/api/fiff/fiff-evoked) &*
  Evoked data.

- **inverse** : *const [MNEInverseOperator](/docs/api/mne/mne-inverse-operator) &*
  Inverse operator.

**Returns:**

- *std::pair&lt; Eigen::VectorXd, Eigen::VectorXd &gt;* — [`Pair`](/docs/api/inv/pair) of (snr, snrEst), one value per time point.

### compute_whitener(noiseCov, rank)

```cpp
std::pair< Eigen::MatrixXd, int > compute_whitener(const [FiffCov](/docs/api/fiff/fiff-cov) & noiseCov, int rank);
```

Compute whitening matrix from a noise covariance.

Returns a whitening matrix W such that W * data has identity covariance. Matches MNE-Python's mne.cov.compute_whitener().

**Parameters:**

- **noiseCov** : *const [FiffCov](/docs/api/fiff/fiff-cov) &*
  Noise covariance matrix.

- **rank** : *int*
  Desired rank (0 = auto from eigenvalues).

**Returns:**

- *std::pair&lt; Eigen::MatrixXd, int &gt;* — [`Pair`](/docs/api/inv/pair) of (whitener matrix, effective rank).

### compute_source_psd(stc, sfreq, fmin, fmax, nFft)

```cpp
std::pair< Eigen::MatrixXd, Eigen::VectorXd > compute_source_psd(const [InvSourceEstimate](/docs/api/inv/inv-source-estimate) & stc, float sfreq, float fmin, float fmax, int nFft);
```

Compute PSD for a source estimate using Welch's method.

Takes a source estimate (n_sources x n_times) and computes the power spectral density at each source vertex. Equivalent to MNE-Python's mne.minimum_norm.compute_source_psd().

**Parameters:**

- **stc** : *const [InvSourceEstimate](/docs/api/inv/inv-source-estimate) &*
  Source estimate.

- **sfreq** : *float*
  Sampling frequency (Hz).

- **fmin** : *float*
  Minimum frequency of interest (Hz).

- **fmax** : *float*
  Maximum frequency of interest (Hz).

- **nFft** : *int*
  FFT length (0 = use data length).

**Returns:**

- *std::pair&lt; Eigen::MatrixXd, Eigen::VectorXd &gt;* — [`Pair`](/docs/api/inv/pair) of (PSD matrix [n_sources x n_freqs], frequency vector).

std::map< std::string, Eigen::VectorXd > compute_source_band_power(const [InvSourceEstimate](/docs/api/inv/inv-source-estimate) & stc, float sfreq, const std::map< std::string, std::pair< float, float > > & bands);

Compute band power for source estimate.

**Returns:**

- *std::map&lt; std::string, Eigen::VectorXd &gt;* — Map of band name -&gt; power vector (n_sources).
