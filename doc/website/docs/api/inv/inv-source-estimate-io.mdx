## Static Methods

### write_csv(stc, path, delim)

Export source estimate to CSV format.

Writes a header line with vertex indices, then one row per time point. First column is time (seconds). Numbers are written in the shortest form that reads back to the same value.

**Parameters:**

- **stc** : *const [InvSourceEstimate](/docs/api/inv/inv-source-estimate) &*
  Source estimate to export.

- **path** : *const std::filesystem::path &*
  Output file path.

- **delim** : *char*
  Delimiter character (default comma).

**Returns:**

- *bool* — true if successful.

---

### read_csv(path, delim)

Read source estimate from CSV format.

**Parameters:**

- **path** : *const std::filesystem::path &*
  Input file path.

- **delim** : *char*
  Delimiter character (default comma).

**Returns:**

- *[InvSourceEstimate](/docs/api/inv/inv-source-estimate)* — Source estimate; empty if the file cannot be read, a field is not a number or a row does not hold one value per vertex.

---

### write_matrix(stc, path)

Export source estimate as a tab-separated matrix for easy import.

No header; pure numeric matrix (n_vertices × n_times).

**Parameters:**

- **stc** : *const [InvSourceEstimate](/docs/api/inv/inv-source-estimate) &*
  Source estimate to export.

- **path** : *const std::filesystem::path &*
  Output file path.

**Returns:**

- *bool* — true if successful.

const std::filesystem::path csvPath = tmp.filePath("v1-dspm.csv").toStdU16String();
