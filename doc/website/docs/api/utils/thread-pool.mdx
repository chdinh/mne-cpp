# ThreadPool

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library &nbsp;·&nbsp; **Source:** [`utils/thread_pool.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/utils/thread_pool.h)

`#include <utils/thread_pool.h>`

```cpp
class UTILSLIB::ThreadPool
```

Runs tasks on a fixed set of worker threads.

`parallelFor()` and `parallelMap()` block until done, and the calling thread works through the range too, so they may be nested or called from a task of the same pool without deadlocking.

```cpp title="src/examples/ex_utils/main.cpp"
const std::vector<int> channels = {0, 1, 2, 3};
const std::vector<double> power = ThreadPool::global().parallelMap(channels, [](int ch) { return 0.5 * ch; }); // in order
auto background = ThreadPool::global().submit([] { return 42; });
```

### submit(task)

**Parameters:**

  Callable without arguments.

- *std::future&lt; std::invoke_result_t&lt; F &gt; &gt;* — Its result, or the exception it threw.

---

### parallelFor(begin, end, body)

Calls `body(i)` for every i in [`begin`, `end`) and returns when all calls have finished.

**Parameters:**

- **begin** : *std::size_t*
  First index.

- **end** : *std::size_t*
  One past the last index; an empty range does nothing.

- **body** : *const std::function&lt; void(std::size_t)&gt; &*
  Called once per index, from any thread.

---

### parallelMap(input, f)

**Parameters:**

- **input** : *const std::vector&lt; T &gt; &*
  The values.

- **f** : *F*
  Called once per value, from any thread.

**Returns:**

- *std::vector&lt; std::invoke_result_t&lt; F, const T & &gt; &gt;* — f applied to every value of `input`, in the order of `input`.
