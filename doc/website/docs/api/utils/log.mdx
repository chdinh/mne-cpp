# Log

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library &nbsp;·&nbsp; **Source:** [`utils/generics/log.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/utils/generics/log.h)

`#include <utils/log.h>`

```cpp
class UTILSLIB::Log
```

Writes library messages to the current sink; thread-safe.

```cpp title="src/examples/ex_utils/main.cpp"
Log::warning("channel {} is flat", "MEG 0113"); // formatted as by std::format, then passed to Qt's handler
```

## Static Methods

### write(level, message)

Hands `message` to the current sink.

**Parameters:**

- **level** : *Level*
  Severity.

- **message** : *std::string_view*
  UTF-8 text.

### set_sink(sink)

Replaces the sink.

**Parameters:**

- **sink** : *Sink*
  The new sink; an empty one restores forwarding to Qt's message handler.

**Returns:**

- *Sink* — The sink that was installed before, empty if messages were forwarded to Qt.
