# LogCapture

**Namespace:** `UTILSLIB` &nbsp;·&nbsp; **Library:** Utilities Library &nbsp;·&nbsp; **Source:** [`utils/generics/log.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/utils/generics/log.h)

`#include <utils/log.h>`

```cpp
class UTILSLIB::LogCapture
```

Records every message instead of passing it on, while it exists; replaces `QTest::ignoreMessage`.

The sink installed before is restored on destruction, so captures nest when destroyed in reverse order.

```cpp title="src/examples/ex_utils/main.cpp"
LogCapture capture; // in a test: record instead of printing
Log::warning("channel MEG 0113 is flat");
const int flat = capture.count(Log::Level::Warning, "flat");
```
