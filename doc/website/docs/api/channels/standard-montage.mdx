# StandardMontage

**Namespace:** `CHANNELSLIB` &nbsp;·&nbsp; **Library:** Channels Library &nbsp;·&nbsp; **Source:** [`channels/standard_montage.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/channels/standard_montage.h)

:::info[Python equivalent]
`mne.channels.make_standard_montage` in MNE-Python.
:::

`#include <channels/standard_montage.h>`

```cpp
class CHANNELSLIB::StandardMontage
```

Standard EEG montage with named electrode positions.

```cpp title="src/examples/ex_channels/main.cpp"
const std::vector<ElectrodePosition> montage1020 = StandardMontage::montage(StandardMontage::System::Standard_1020);
const std::optional<Vector3d> cz = StandardMontage::find_electrode("Cz"); // mne's standard_1005 positions, metres, MNI frame
```

## Static Methods

### montage(system)

The electrodes of a montage system.

**Parameters:**

- **system** : *System*
  The montage system.

**Returns:**

- *std::vector&lt; [ElectrodePosition](/docs/api/channels/electrode-position) &gt;* — The electrode positions.

---

### electrode_names(system)

The electrode names of a montage system.

**Parameters:**

- **system** : *System*
  The montage system.

**Returns:**

- *BASELIB::StringList* — The electrode names, in montage order.

---

### find_electrode(name)

Looks up an electrode of the standard_1005 table, fiducials included.

**Parameters:**

- **name** : *std::string_view*
  Electrode name, case-insensitive.

**Returns:**

- *std::optional&lt; Eigen::Vector3d &gt;* — The position, or no value if the name is unknown.

---

### electrode_count(system)

The number of electrodes of a montage system.

**Parameters:**

- **system** : *System*
  The montage system.

**Returns:**

- *std::size_t* — The electrode count.
