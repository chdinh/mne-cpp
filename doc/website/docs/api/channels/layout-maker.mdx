# LayoutMaker

**Namespace:** `CHANNELSLIB` &nbsp;·&nbsp; **Library:** Channels Library &nbsp;·&nbsp; **Source:** [`channels/layoutmaker.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/channels/layoutmaker.h)

Makes 2-D channel layouts from 3-D sensor positions.

Makes 2-D channel layouts from 3-D sensor positions.

```cpp title="src/examples/ex_channels/main.cpp"
// Azimuthal equidistant projection around the fitted sphere: Cz lands near the centre, the nose points up
std::vector<Vector3d> positions;
StringList names;
for (const ElectrodePosition& electrode : montage1020) {
    positions.push_back(electrode.pos);
    names.push_back(electrode.name);
}
const LayoutOptions options{.radius = 20.0, .box_width = 5.0, .box_height = 4.0};
const auto layout = LayoutMaker::make_layout(positions, options);
if (layout)
    LayoutMaker::write_lout(dir / "1020.lout", *layout, names, options);
```

---

## Static Methods

### make_layout(positions, options)

Projects 3-D positions onto the plane.

**Parameters:**

- **positions** : *std::span&lt; const Eigen::Vector3d &gt;*
  The sensor positions.

- **options** : *const [LayoutOptions](/docs/api/channels/layout-options) &*
  Projection and box size.

**Returns:**

- *std::optional&lt; std::vector&lt; Eigen::Vector2d &gt; &gt;* — The lower-left corner of each channel box, or no value if there are no positions or all coincide.

---

### write_lout(path, corners, names, options)

Writes channel boxes as an MNE-C .lout file.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The output file.

- **corners** : *std::span&lt; const Eigen::Vector2d &gt;*
  The lower-left corner of each box, as returned by `make_layout()`.

- **names** : *const BASELIB::StringList &*
  The channel names; boxes without a name are written unnamed.

- **options** : *const [LayoutOptions](/docs/api/channels/layout-options) &*
  The box size.

**Returns:**

- *bool* — Whether the file was written.
