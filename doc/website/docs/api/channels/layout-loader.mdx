# LayoutLoader

**Namespace:** `CHANNELSLIB` &nbsp;·&nbsp; **Library:** Channels Library &nbsp;·&nbsp; **Source:** [`channels/layoutloader.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/channels/layoutloader.h)

`#include <channels/layoutloader.h>`

```cpp
class CHANNELSLIB::LayoutLoader
```

Reads ANT/ASA .elc files, which hold the electrode positions of an EEG cap.

Reads ANT/ASA .elc electrode files.

```cpp title="src/examples/ex_channels/main.cpp"
// ANT .elc electrode file: names, 3-D positions and their unit
const std::optional<ElectrodeLayout> cap = LayoutLoader::read_elc(dir / "cap.elc");
```

---

## Static Methods

### read_elc(path)

Reads an .elc file.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The .elc file.

**Returns:**

- *std::optional&lt; [ElectrodeLayout](/docs/api/channels/electrode-layout) &gt;* — The electrodes, or no value if the file has no .elc extension, cannot be opened or is malformed.

---

### parse_elc(text)

Parses the text of an .elc file.

Position lines are `"name : x y z"` or plain `"x y z"`; the names of a Labels block take precedence. Lines starting with `#` are comments.

**Parameters:**

- **text** : *std::string_view*
  The file contents.

**Returns:**

- *std::optional&lt; [ElectrodeLayout](/docs/api/channels/electrode-layout) &gt;* — The electrodes, or no value if there are none or names and positions do not pair up.
