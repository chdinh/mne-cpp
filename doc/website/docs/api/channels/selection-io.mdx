# SelectionIO

**Namespace:** `CHANNELSLIB` &nbsp;·&nbsp; **Library:** Channels Library &nbsp;·&nbsp; **Source:** [`channels/selectionio.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/channels/selectionio.h)

`#include <channels/selectionio.h>`

```cpp
class CHANNELSLIB::SelectionIO
```

Reads and writes channel selection groups.

Reader/writer for MNE .sel channel-selection files and Brainstorm .mon montage files.

```cpp title="src/examples/ex_channels/main.cpp"
// MNE .sel: one "name:ch1|ch2|..." group per line, read back in file order
const std::vector<ChannelSelection> selections{{"Left-temporal", {"MEG0111", "MEG0112", "MEG0113"}}, {"Vertex", {"MEG0711"}}};
SelectionIO::write_sel(dir / "groups.sel", selections);
const auto reread = SelectionIO::read_sel(dir / "groups.sel");
```

---

## Static Methods

### read_sel(path)

Reads an MNE .sel file: one `"name:ch1|ch2|..."` group per line, `%` lines are comments.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The .sel file.

**Returns:**

- *std::optional&lt; std::vector&lt; [ChannelSelection](/docs/api/channels/channel-selection) &gt; &gt;* — The groups in file order, or no value if the path has no .sel extension or cannot be opened.

---

### read_mon(path)

Reads a Brainstorm .mon file: the group name, then one `"channel : expression"` line per channel.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The .mon file.

**Returns:**

- *std::optional&lt; [ChannelSelection](/docs/api/channels/channel-selection) &gt;* — The group, or no value if the path has no .mon extension or cannot be opened.

---

### write_sel(path, groups)

Writes groups to an MNE .sel file.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The .sel file.

- **groups** : *std::span&lt; const [ChannelSelection](/docs/api/channels/channel-selection) &gt;*
  The groups.

**Returns:**

- *bool* — Whether the file was written; false if the path has no .sel extension.

---

### write_mon(directory, groups)

Writes each group to its own Brainstorm .mon file, named after the group.

**Parameters:**

- **directory** : *const std::filesystem::path &*
  The directory to write to.

- **groups** : *std::span&lt; const [ChannelSelection](/docs/api/channels/channel-selection) &gt;*
  The groups.

**Returns:**

- *bool* — Whether every file was written.
