# Log

**Namespace:** `BASELIB` &nbsp;·&nbsp; **Library:** Base Library &nbsp;·&nbsp; **Source:** [`base/log.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/base/log.h)

`#include <base/log.h>`

```cpp
class BASELIB::Log
```

Writes library messages to the current sink; thread-safe.

```cpp title="src/examples/ex_base/main.cpp"
Log::warning("channel {} is flat", "MEG 0113"); // formatted as by std::format
```

```cpp title="src/examples/ex_base/main.cpp"
Log::install_qt_message_handler();  // console output
Log::set_file(dir / "example.log"); // and a plain-text copy
Log::info("logging to {}", utf8FromPath(Log::file()));
```

## Static Methods

### write(level, message)

Hands `message` to the current sink, unless `level` is below `level()`.

**Parameters:**

- **level** : *Level*
  Severity.

- **message** : *std::string_view*
  UTF-8 text.

### set_level(level)

Sets the lowest level that is written; messages below it are dropped before they are formatted.

**Parameters:**

- **level** : *Level*
  The new threshold; the default is the MNE_LOG_LEVEL build option.

**Returns:**

- *Level* — The threshold before.

---

### level()

**Returns:**

- *Level* — The lowest level that is written.

---

### enabled(level)

**Parameters:**

- **level** : *Level*
  The severity to check.

**Returns:**

- *bool* — Whether messages of `level` are written.

---

### set_sink(sink)

Replaces the sink.

**Parameters:**

- **sink** : *Sink*
  The new sink; an empty one restores forwarding to Qt's message handler.

**Returns:**

- *Sink* — The sink that was installed before, empty if messages were forwarded to Qt.

---

### install_qt_message_handler()

Installs the Qt message handler that prints every Qt message, and so every forwarded [`Log`](/docs/api/base/log) message, at or above `level()`: results to stdout, diagnostics to stderr, with coloured level tags when built with MNE_LOG_MODE=FORMATTED.

---

### set_file(path)

Additionally writes every message printed by `install_qt_message_handler()` to a log file, appended, one timestamped and level-tagged line per message.

**Parameters:**

- **path** : *const std::filesystem::path &*
  The log file; an empty path stops file logging.

**Returns:**

- *bool* — Whether the file could be opened for writing.

---

### file()

**Returns:**

- *std::filesystem::path* — The log file, empty if file logging is off.
