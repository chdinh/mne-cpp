# LogCapture

**Namespace:** `BASELIB` &nbsp;·&nbsp; **Library:** Base Library &nbsp;·&nbsp; **Source:** [`base/log.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/base/log.h)

`#include <base/log.h>`

```cpp
class BASELIB::LogCapture
```

Records every message instead of passing it on, while it exists; replaces `QTest::ignoreMessage`.

Records every level; the sink and level before are restored on destruction, so captures nest when destroyed in reverse order.

```cpp title="src/examples/ex_base/main.cpp"
LogCapture capture; // in a test: record instead of printing
Log::warning("channel MEG 0113 is flat");
const int flat = capture.count(Log::Level::Warning, "flat");
```
