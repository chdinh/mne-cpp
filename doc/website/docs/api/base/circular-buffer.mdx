# CircularBuffer

**Namespace:** `BASELIB` &nbsp;·&nbsp; **Library:** Base Library &nbsp;·&nbsp; **Source:** [`base/circular_buffer.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/base/circular_buffer.h)

`#include <base/circular_buffer.h>`

```cpp
template <typename T>
class BASELIB::CircularBuffer
```

Fixed-capacity first-in first-out queue; push waits while it is full and pop while it is empty, each for at most the timeout.

```cpp title="src/examples/ex_base/main.cpp"
CircularBuffer<double> buffer(4); // one thread pushes, another pops
buffer.push(std::array{1.0, 2.0, 3.0});
double first = 0.0;
double second = 0.0;
buffer.pop(first);
buffer.pop(second);
```

### push(elements)

Appends all of `elements`, or none.

**Parameters:**

- **elements** : *std::span&lt; const T &gt;*
  The elements to append, in order.

**Returns:**

- *bool* — Whether there was room for all of them before the timeout.

---

### pop(element)

Removes the oldest element.

**Parameters:**

- **element** : *T &*
  Receives the element; unchanged if none arrived before the timeout.

**Returns:**

- *bool* — Whether an element was removed.

CircularBuffer<double> buffer(4); // one thread pushes, another pops
