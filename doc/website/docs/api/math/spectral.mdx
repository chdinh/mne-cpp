# Spectral

**Namespace:** `MATHLIB` &nbsp;·&nbsp; **Library:** Math Library &nbsp;·&nbsp; **Source:** [`math/spectral.h`](https://github.com/mne-tools/mne-cpp/blob/staging/src/libraries/math/spectral.h)

`#include <math/spectral.h>`

```cpp
class MATHLIB::Spectral
```

Static multi-taper spectral estimator producing tapered spectra, PSDs and cross-spectral density matrices over `Eigen` row inputs.

Designed for fan-out across channels on std::async tasks and feeding `CONNECTIVITYLIB`'s coherence / phase estimators.

Static multi-taper spectra, PSD and CSD estimator for MEG/EEG time series.

```cpp title="src/examples/ex_math/main.cpp"
const int nSamples = 200;
const double sFreq = 100.0;
RowVectorXd signal(nSamples);
for (int t = 0; t < nSamples; ++t) {
    signal(t) = 2.0 * std::sin(2.0 * kPi * 10.0 * t / sFreq); // 10 Hz, amplitude 2
}
const auto [tapers, weights] = Spectral::generateTapers(nSamples, std::string("hanning"));
const MatrixXcd spectra = Spectral::computeTaperedSpectraRow(signal, tapers, nSamples);
const RowVectorXd psd = Spectral::psdFromTaperedSpectra(spectra, weights, nSamples, sFreq);
const VectorXd freqs = Spectral::calculateFFTFreqs(nSamples, sFreq);
```

### [ex_math](../../examples/math/ex_math.mdx)

Math library on inputs with known answers.

````cpp title="src/examples/ex_math/main.cpp, line 125"
const auto [tapers, weights] = Spectral::generateTapers(nSamples, std::string("hanning"));
const MatrixXcd spectra = Spectral::computeTaperedSpectraRow(signal, tapers, nSamples);
const RowVectorXd psd = Spectral::psdFromTaperedSpectra(spectra, weights, nSamples, sFreq);
const VectorXd freqs = Spectral::calculateFFTFreqs(nSamples, sFreq);
Index peak = 0;
psd.maxCoeff(&peak);
const double power = psd.sum() * (freqs(1) - freqs(0)); // integrated one-sided PSD = signal variance
ok &= expect(freqs.size() == nSamples / 2 + 1 && std::fabs(freqs(peak) - 10.0) < 1e-12,
             std::format("PSD peaks at {:g} Hz; {} bins match numpy.fft.rfftfreq", freqs(peak), freqs.size()));
ok &= expect(std::fabs(power - 2.0) < 0.05, std::format("Parseval: integrated PSD {:g} = variance 2", power));
````
