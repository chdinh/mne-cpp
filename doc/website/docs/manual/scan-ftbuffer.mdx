# FieldTrip Buffer

The FtBuffer plugin reads a FieldTrip buffer server through the `ftbuffer://` source of the `mne_acq_devices` library.
It is only a client: it reads what a producer puts into the buffer and has no access to the device itself. Without a
server it simulates `neuromag2ft` on a Neuromag system.

The setup widget sets

- **Host** and **Port** of the buffer server (default `localhost` and `1972`).
- **Samples per block**: the block size handed to the connected plugins.
- **Simulate neuromag2ft and its buffer**: a 306-channel Neuromag system relayed into a simulated buffer.

On start the plugin waits for the producer's header and then streams the samples put after that moment. With the
Neuromag header of `neuromag2ft`, the channels, their coil types and positions, the measurement info and the
digitizer points of the acquisition are used, the samples are already in tesla and volts, and changes of `STI 014`
(or `STI101`) become events. Other producers give the channel names of their header, or numbered channels. Events put
into the buffer with a numeric value become events with that code. When the producer puts a new header, i.e. starts a
new measurement, the stream ends; start the plugin again.

## Running with Neuromag / Elekta / MEGIN

1. Download FieldTrip `neuromag2ft`

   Download the FieldTrip source code on your acquisition computer, either from their
   [website](http://www.fieldtriptoolbox.org/download/) or their [GitHub page](https://github.com/fieldtrip/fieldtrip).
   The executable `neuromag2ft` both hosts the buffer and puts the acquisition's data into it.

2. Get `neuromag2ft` set up

   Depending on your system, you might have to build it locally with `make` in `/realtime/src/acquisition/neuromag/`.
   If in doubt, follow the [documentation](http://www.fieldtriptoolbox.org/development/realtime/neuromag/) of the
   FieldTrip buffer.

3. Run `neuromag2ft`

   Run `neuromag2ft` on the acquisition computer before the measurement starts; `--help` lists its options. By
   default the buffer listens on port `1972`.

4. Set up the plugin in MNE Scan

   Select the `FtBuffer` plugin, enter the address of the acquisition computer and the port, and start MNE Scan.

The [Neuromag](./scan-neuromag.mdx) plugin reads the acquisition directly, without `neuromag2ft`, but runs on the
acquisition computer itself.

## Simulation and scripting

The same source is available to every program that links `mne_acq_devices`:

```cpp
#include <acq/acq_device.h>
#include <acq/devices/acq_devices.h>

ACQLIB::register_ftbuffer_scheme();
auto device = ACQLIB::AcqDevice::open("ftbuffer://megacq:1972");
```

`timeout` is how long to wait for the connection and the producer's header. `ftbuffer://?simulate=1` accepts `meg`,
`eeg`, `rate`, `block` (samples per put), `seed`, `realtime=0` (as fast as possible) and `duration` in seconds.
