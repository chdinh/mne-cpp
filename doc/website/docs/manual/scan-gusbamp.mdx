# GUSBAmp

The GUSBAmp plugin streams up to four synchronised g.tec g.USBamp amplifiers into MNE Scan through the `gusbamp://`
source of the `mne_acq_devices` library. Without amplifiers it simulates them.

## Building and running

The plugin is built by default. On Windows it loads the g.USBamp API (`gUSBamp.dll`) from the system directory at run
time; the amplifier's USB driver installs it there. Connect the units with the synchronisation cable and switch them on
before starting the acquisition. The setup widget sets

- **Serial numbers**: the units, separated by commas, master first (e.g. `UB-2015.05.16,UB-2015.05.17`); empty for the
  first connected unit.
- **Inputs**: the inputs 1 to 16 acquired on every unit, e.g. `1-8,11`.
- **Sample rate**: 32, 64, 128, 256, 512, 600, 1200, 2400, 4800, 9600, 19200 or 38400 Hz.
- **Samples per block**: the block size handed to the connected plugins.
- **Trigger line**: the master's trigger input as `STI 014`; its changes become events.
- **Simulate the amplifiers**: synthetic EEG and trigger codes in the API's format, for the given serial numbers.

The channels are `EEG 001` onwards, the inputs of the master first, then those of each slave. The amplifiers run
without their hardware filters, unipolar, with no common reference or ground.

## Simulation and scripting

The same source is available to every program that links `mne_acq_devices`:

```cpp
#include <acq/acq_device.h>
#include <acq/devices/acq_devices.h>

ACQLIB::register_gusbamp_scheme();
auto device = ACQLIB::AcqDevice::open("gusbamp://UB-1,UB-2?simulate=1&inputs=1-8&rate=512&trigger=1");
auto impedances = device->measureImpedances();
```

`simulate=1` also accepts `seed`, `realtime=0` (as fast as possible), `duration` in seconds and `gain`.
