# BrainAmp

The BrainAmp plugin streams Brain Products BrainAmp amplifiers into MNE Scan through the `brainamp://` source of the
`mne_acq_devices` library. Without an amplifier it simulates one.

## Building

The plugin is built by default. To talk to a real amplifier on Windows, copy `BrainAmpIoCtl.h` from the BrainAmp SDK
into `src/applications/mne_scan/plugins/brainamp`, or point CMake at the directory that holds it:

```bash
cmake -B build -DMNE_BRAINAMP_SDK_DIR=C:/BrainAmpSDK
```

Without the header the source only simulates.

## Running

Install the BrainAmp USB driver from the software that came with the amplifier and switch the amplifier on before
starting MNE Scan. The setup widget sets

- **Channels**: EEG channels, 32 per amplifier and up to 128. The amplifiers must be connected in order.
- **Resolution**: the step of one bit, 100 nV, 500 nV, 10 µV or 152.6 µV.
- **Samples per block**: samples handed to the connected plugins at once.
- **Simulate the amplifier**: streams the amplifier's wire format with synthetic EEG and trigger codes.

The amplifier samples at 5000 Hz. The marker word arrives as the stimulus channel `STI 014`.

## Simulation and scripting

The same source is available to every program that links `mne_acq_devices`:

```cpp
#include <acq/acq_device.h>
#include <acq/devices/acq_devices.h>

ACQLIB::registerBrainAmpScheme();
auto device = ACQLIB::AcqDevice::open("brainamp://?simulate=1&channels=64&resolution=500nV");
```

`simulate=1` also accepts `seed`, `realtime=0` (as fast as possible), `duration` in seconds and `gain`.
