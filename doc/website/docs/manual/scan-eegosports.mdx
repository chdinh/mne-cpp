# EEGoSports

The EEGoSports plugin streams ANT Neuro eego amplifiers into MNE Scan through the `eego://` source of the
`mne_acq_devices` library. Without an amplifier it simulates one.

## Building and running

The plugin is built by default. At run time the source loads the eego SDK library (`eego-SDK.dll` on Windows,
`libeego-SDK.so` on Linux), which ANT Neuro ships with the amplifier, from the path in the environment variable
`MNE_CPP_EEGO_SDK` or else through the system loader. Switch the amplifier on before starting the acquisition. The
setup widget sets

- **Sampling frequency**: one of the amplifier's rates, 512 Hz by default.
- **Block size**: the samples per block handed to the connected plugins.
- **Simulate the amplifier**: 64 referential and 24 bipolar inputs that stream synthetic EEG and trigger codes in the
  SDK's format.

The referential inputs are named and placed after the electrodes of the cap layout chosen in the project setup,
which also sets the cardinal points: tracked ones from their own `.elc` file, or electrodes of the cap lowered by a
given distance. The bipolar inputs are `BIP 1` onwards, the trigger input `STI 014`, and the amplifier's sample counter
`COUNTER`. The **Check impedance values** action measures the electrode impedances, also of the simulated amplifier.

## Simulation and scripting

The same source is available to every program that links `mne_acq_devices`:

```cpp
#include <acq/acq_device.h>
#include <acq/devices/acq_devices.h>

ACQLIB::register_eego_scheme();
auto device = ACQLIB::AcqDevice::open("eego://?simulate=1&reference=32&bipolar=0&rate=1000");
auto impedances = device->measureImpedances();
```

The target selects an amplifier by serial number (`eego://000123`); `sdk=` gives the SDK library's path, and
`reference_range` and `bipolar_range` the input ranges in volts. `simulate=1` also accepts `seed`, `realtime=0` (as fast
as possible), `duration` in seconds and `gain`.
