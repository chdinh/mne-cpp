# mne_fix_stim14

## Overview

`mne_fix_stim14` fixes the trigger channels of raw FIFF files in place, as the MNE-C tool of the same name by
Matti Hämäläinen does.

- By default the digital trigger channel `STI 014` gets the range 1 and keeps only the low byte of each sample, which
  removes stray high bits from the trigger codes. This works on 16-bit data buffers.
- With `--32`, `STI101` and `STI201` keep only the low 16 bits of each sample, for 32-bit integer and float data.

A file is checked completely before anything in it changes: a file without the trigger channels, or with data buffers
of another type, stays as it was, and the tool exits with 1.

## Usage

```bash
mne_fix_stim14 [--32] <file> ...
```

## Options

| Option | Description |
|---|---|
| `--32` | Keep only the two lowest bytes of `STI101` and `STI201` (32-bit integer and float data) |
| `--help` | Print help |
| `--version` | Print version |

## Example

```bash
cp sam-raw.fif sam-fixed-raw.fif
mne_fix_stim14 sam-fixed-raw.fif
```
